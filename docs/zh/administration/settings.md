# 设置

Paperclip 拥有两个设置界面，明确您正在查看哪一个至关重要。

**个人资料** 是 *您* 的账户——包括您的显示名称以及显示在您的评论旁边的头像。修改它仅影响 *您* 的呈现方式。同一实例上的其他看板用户拥有各自独立的个人资料，并看到自己的信息。

**实例设置** 是管理员控制项。它们并不位于单独的实例页面上——您通过与您组织相同的 **设置** 导航入口访问它们（包括 **访问权限**、**实验性**、**插件** 和 **适配器** 等选项卡，以及 **常规** 页面中的实例部分）。您在那里所做的任何更改都将应用于整个 Paperclip 实例——涵盖每个公司、每个用户以及在此安装中运行的每个智能体。如果您在托管五个公司的 VPS 上运行 Paperclip，实例开关的切换将对这五个公司全部生效。

公司设置和实例设置现在共享同一导航。下文描述的实例级 **常规** 控制项位于组织自身的 **常规** 页面（参见 [公司管理](./company.md#general-settings)），因此实例管理员可以从与组织设置相同的位置访问它们，而非通过单独的区域。

本指南将逐节介绍这两个界面。

## 个人资料

![个人资料设置](../../user-guides/screenshots/light/settings/profile.png)

要到达此处，点击侧边栏底部的头像以打开账户菜单，然后点击菜单顶部的图片和名称。这将打开您的公开个人资料页面；在那里点击 **编辑个人资料** 即可进入此页面。该页面仅针对您——当您编辑自己的个人资料时，其他用户的个人资料不会发生变化。

> **提示：** 当您被允许邀请他人时，账户菜单中还会包含一个 **邀请** 行。在自托管实例上，它会打开 **成员** 页面的 **邀请** 选项卡，并且仅对公司所有者和管理员、实例管理员以及本地看板可见。在 Paperclip Cloud 上，它则会打开您堆栈的人员设置，且仅对堆栈的所有者或管理员可见。

您有三项内容可供操作：

- **头像** — 点击圆形图片（或 **上传照片** 按钮）可从磁盘选择新图像。该图像将上传至当前所选公司的资产空间中的 Paperclip 文件存储。如果未选择公司，则无法上传——页面会提示您先选择一个公司。一旦设置了图像，上传控件旁边会出现一个 **移除** 按钮。
- **显示名称** — 显示在侧边栏账户页脚中，并作为您发布的任何评论的作者名称。如果留空，则回退为 "Board"。该字段限制为 120 个字符。
- **电子邮件** — 只读。您的电子邮件由身份验证会话（登录提供商）管理，而非由此页面管理。如果需要更改，请在您登录的来源处更新。

点击 **保存个人资料** 以持久化名称或头像的更改。当名称为空或保存操作正在进行时，该按钮将被禁用。

> **注意：** 头像作为资产存储在 *所选公司* 下，但个人资料本身是用户级别的记录。如果您稍后在侧边栏中切换所选公司，您的头像仍会继续正常工作——只是新的上传将归属于上传时处于活动状态的公司。

### 键盘快捷键

键盘快捷键对所有已登录用户始终开启——此处或任何地方都没有需要开启的开关。这涵盖了收件箱和任务列表导航以及全局快捷键：`c` 用于创建任务，`/` 用于搜索，`?` 用于快捷键速查表，以及 `[` 和 `]` 用于切换侧边栏和侧面板。

快捷键在您输入时会避免干扰：它们会忽略文本字段内的按键，并且在对话框打开时不会触发。

> **从旧版本升级？** 早期版本有一个 **键盘快捷键** 开关——最初位于实例 **常规** 页面，随后位于此个人资料页面，默认关闭。这两个开关均已移除，因此升级后，快捷键将对每个已登录用户直接生效。

## 实例：常规

![常规设置页面，顶部为组织字段；实例级部分位于同一页面的下方](../../user-guides/screenshots/light/settings/instance-general.png)

不再有单独的实例常规页面。打开 **设置** 即可到达 **常规** 页面——这是设置侧边栏中的第一项。该页面的顶部包含您组织自身的设置（**组织名称**、**描述**、**Logo**、招聘以及交互治理）。滚动经过 **交互治理** 后，您将达到下文描述的实例级部分，它们位于 **危险区域** 的上方。在这里，您可以查看实例的部署方式并切换几个跨切面的开关。

> **从旧版本升级？** 指向实例常规或心跳页面的旧链接仍然有效——它们会重定向到此 **常规** 页面。

### 部署与身份验证

在 **部署与身份验证** 标题旁边，一个小模式徽章会告诉您该实例正在运行哪种部署配置文件。下方的文字解释了其实际含义：

- **本地受信任** — 实例将浏览器请求视为本地看板操作员。无需登录。这是您在自己的机器上运行 Paperclip 时的默认设置。
- **已认证的公共** — 需要登录，且实例旨在置于公共 URL 上。
- **已认证的私有** — 需要登录，但实例旨在用于私有网络（局域网、VPN 或类似环境）。

三个状态框总结了就绪情况：

- **身份验证就绪状态** — 身份验证子系统是否已完全配置。
- **引导状态** — 如果初始 CEO/董事会设置尚未完成，则显示 "需要设置"，否则显示 "就绪"。
- **引导邀请** — 是否有待处理的活跃首次运行邀请链接。

这些字段仅提供信息。要更改它们，您需要更改部署本身——参见 [环境变量](../../reference/deploy/environment-variables.md)。

### 在日志中隐藏用户名

隐藏主目录路径及类似操作员可见日志输出中的用户名段。如果您正在共享屏幕录制或粘贴转录文本，这将非常有用。默认关闭。请注意，路径字符串之外的裸用户名提及在实时转录视图中不会被屏蔽——这是一个尽力而为的过滤器，而非保证。

### 备份保留

控制自动数据库备份在每个层级的保留时间。Paperclip 大约每小时备份一次，然后随时间推移对备份进行精简：

- **每日** — 每个备份保留所选天数。
- **每周** — 每周保留一个备份，保留所选周数。
- **每月** — 每月保留一个备份，保留所选月数。

每个层级都是预设选择器，因此您只能从经过审核的保留窗口中进行选择。备份在磁盘上以 gzip 格式压缩。更长的保留时间意味着更多的存储空间——仅根据磁盘空间和合规性要求提高保留窗口。

### AI 反馈共享

控制 AI 输出的点赞/点踩投票是否可以将被投票的输出发送至 Paperclip Labs。有两个按钮，外加一个初始状态：

- **尚未保存默认设置** — 初始状态。没有对应的按钮；卡片仅告知您，下一次点赞或点踩将询问一次，然后在此处保存您的答案。
- **始终允许** — 被投票的 AI 输出将自动共享。
- **不允许** — 被投票的 AI 输出保留在本地。

无论此设置如何，本地投票始终会被保存——此设置仅控制 *内容* 是否离开您的实例。同一卡片上还有一个 **阅读我们的服务条款** 链接。

### 退出登录

一个普通的 **退出登录** 按钮，是实例部分的最后一项（位于 **危险区域** 上方）。它将结束您的会话并将您送回登录页面。在本地受信任实例上，通常没有需要退出的内容，但除非操作员已隐藏该按钮，否则它仍会显示。

## 实例：访问权限

![实例访问权限](../../user-guides/screenshots/light/settings/instance-access.png)

实例访问权限是您将用户提升为 **实例管理员** 并选择每个用户可以看到哪些公司的地方。这与您在 *公司内部* 授予的角色不同。

### 实例级与公司级角色

由于这两者感觉相似，明确区分它们很有必要：

- **公司成员资格** 允许用户在一个特定公司内查看和操作。用户可以成为多个公司的成员，每个公司都有各自的成员角色（操作员、经理等）。这是按公司设置的。
- **实例管理员** 可以查看和管理实例本身——添加/移除实例管理员、授予用户公司访问权限，并打开仅限管理员的界面。这是在此页面按用户设置的。

用户可以成为实例管理员而不必是每个公司的成员，也可以成为公司成员而不必是实例管理员。这两个层级是独立的。

### 查找和检查用户

左侧面板是一个搜索框和可滚动的用户列表。输入名称或电子邮件以缩小范围。每一行显示：

- 用户的名称和电子邮件
- 如果当前是实例管理员，则显示绿色盾牌图标
- 活跃公司成员资格的数量

点击用户以在右侧加载其详细信息视图。

### 提升为实例管理员

在详细信息视图中，一个按钮用于切换用户的实例管理员状态：如果用户不是管理员，则显示 **提升为实例管理员**；如果是，则显示 **移除实例管理员**。更改立即生效。请谨慎操作——实例管理员可以授予自己访问任何公司的权限，并可以降低其他实例管理员的权限。

### 公司访问权限

详细信息视图的下半部分是一个网格，列出了实例上的每个公司，每个公司旁边都有一个复选框。勾选该用户应为成员的公司，取消勾选其不应为成员的公司，然后点击 **保存公司访问权限**。

添加访问权限默认创建一个 *活跃操作员* 成员资格。如果用户需要该公司内的更高角色（例如经理），请切换到该公司并在那里提高其角色——此页面仅控制 *是否* 拥有访问权限，而不控制其拥有 *什么角色*。

在复选框网格下方，**当前成员资格** 列出了实际记录的内容，包括角色、状态和最后更新日期。请将其视为真实来源——如果它与您在复选框中设置的内容不匹配，请重新保存。

> **提示：** 正在运行托管多个公司的 VPS 实例？使用此页面在不共享数据库的情况下接入新用户。创建他们的身份验证账户（通过您的登录提供商），在此处找到他们，勾选他们需要的公司，然后保存。

## 实例：适配器

![实例适配器](../../user-guides/screenshots/light/settings/instance-adapters.png)

适配器页面（**设置 → 适配器**）是操作员查看当前注册在此 Paperclip 安装中的每个适配器的界面。适配器是 Paperclip 与 AI 运行时（如 Claude 的本地 CLI、Codex、OpenAI、OpenClaw 等）通信的方式——因此，当您需要添加新运行时、从智能体招聘菜单中隐藏某个运行时，或将运行时包升级到新版本时，请使用此界面。

> **Alpha 版：** 外部适配器系统仍在积极开发中。API 和存储格式可能在版本之间发生变化——在需要时使用此页面，但请预期细节会持续演变。

### 已安装的适配器

页面分为两个部分，从上到下堆叠：

- **外部适配器** — 您自行添加的任何内容，无论是来自 npm 包还是本地路径。每一行显示适配器的显示标签、其注册的 `type`、包名称、版本以及适配器暴露的模型数量。
- **内置适配器** — 随 Paperclip 本身一起提供的适配器。它们不能被移除，只能被隐藏。如果外部适配器覆盖了内置适配器（例如，从 npm 安装的 Claude 适配器分支版本），您还会看到一个合成的 "内置" 行，标记为 **被……覆盖**，以便明确哪个内置适配器被遮蔽。

每个外部适配器旁边有一个小来源图标：从本地路径安装的适配器显示为文件夹图标，从 npm 安装的适配器显示为包图标。版本以等宽字体的 `v1.2.3` 徽章形式显示。

### 健康状态

行徽章是读取适配器健康状况的最快方式：

- **外部** / **内置** — 适配器的来源。
- **v{version}** — 当前加载的包版本。
- **覆盖内置** — 此外部适配器正在替换具有相同 `type` 的内置适配器。
- **从菜单中隐藏** / **覆盖已暂停** — 适配器仍然存在，但在创建或招聘智能体时不提供。使用此功能可在不卸载的情况下暂存发布。

在标签下方，副标题行显示 `type`、npm 包名称（当与类型不同时）以及模型数量。零模型计数通常意味着适配器已加载但无法枚举模型——在将其启用给智能体之前，请检查包配置。

### 启用 / 禁用

每一行右侧都有一个 **电源** 图标。点击它可切换适配器的可见性，而不会删除任何内容：

- 对于常规适配器（包括内置和普通外部适配器），电源按钮切换 **从菜单中隐藏** 状态。隐藏的适配器保持注册状态，且该适配器上的现有智能体继续运行，但在创建新智能体时，适配器下拉菜单中将不包含该适配器。
- 对于 **覆盖内置** 的外部适配器，电源按钮则暂停或恢复覆盖。暂停覆盖会在其下一次运行时将该 `type` 的所有智能体切换回内置实现；恢复则重新启用外部适配器。

外部行上可能还会出现另外两个图标：

- **重新加载**（圆形箭头）在运行进程中热交换适配器模块。在您发布了本地路径适配器的新版本并希望在不重启 Paperclip 的情况下获取更改时非常有用。
- **重新安装**（下载箭头）打开一个确认对话框，检查 npm 注册表中的最新版本，然后拉取并重新安装包。现有智能体将在其下一次运行时使用新版本。

**移除**（垃圾桶）图标仅适用于外部适配器。移除适配器会注销它，拆除其磁盘上的 npm 安装，且无法撤销——Paperclip 会先提示确认。

### 每个适配器的配置

适配器本身在此页面不暴露配置——它们是包，而非可配置的单一实例。每个 **智能体** 选择一个适配器，然后填写该适配器所需的字段（工作目录、环境变量、凭据）。这些每个智能体的字段位于智能体的配置选项卡中，而非此处。

此页面为您提供的是添加、升级和退役填充智能体适配器菜单的适配器包的能力。要安装新的外部适配器，请点击页面右上角的 **安装适配器**。将出现一个对话框，包含两种源模式：

- **npm 包** — 输入包名称（例如 `my-paperclip-adapter`）和可选的版本。Paperclip 从 npm 安装包并注册它。
- **本地路径** — 粘贴指向已签出适配器包的 Linux、WSL 或 Windows 路径。Paperclip 会自动转换 Windows 路径并从磁盘安装适配器。本地路径适配器是在发布前迭代新适配器的最快方式。

在这两种情况下，适配器包必须导出 `createServerAdapter()` — 对话框会提醒您这一契约。

有关 Paperclip 开箱即用的适配器完整目录，以及每个适配器期望的每个智能体字段，请参阅参考文档：[适配器概述](../../reference/adapters/overview.md)。

## 实例：实验性

![实验性设置页面，实验性功能卡片上方有警告横幅](../../user-guides/screenshots/light/settings/experimental.png)

实验性开关使实例启用尚未成为默认的功能。它们在此处受到限制，因为在成熟之前，它们可能会改变行为、性能或迁移。

### 此处的 "实验性" 含义

Paperclip 中的实验性开关是一个具有以下特征的功能：

- 已发布并正常工作，
- 在成为默认设置之前正在根据实际使用情况进行评估，并且
- 可能在未来的版本中被重命名、重构或提升为核心设置。

开启它并不危险（指 "这会破坏您的数据" 意义上的危险）——但实验性功能 **没有兼容性保证**。它们随时可能中断、更改或被移除，且 Paperclip 不承诺为它们提供迁移或长期支持。页面顶部带有此效果的警告。在有理由时切换开关，而非出于好奇；不要依赖实验性功能来维持必须保持稳定的工作流，并在升级时预期需要重读发布说明。

### 可用的开关

打开 **设置 → 实验性**。该页面将其开关分为最多三个部分，并在每个部分内按字母顺序列出卡片。如果某个开关在 [实验性](../../experimental/overview.md) 部分（或本文档的其他地方）拥有自己的页面，其名称将链接到该页面。

**实验性功能** — *"仍在评估中的可选产品功能。"*

- **[智能体聊天](../../experimental/agent-chat.md)** — 每个智能体一个持续对话。**聊天** 位于 **工作** 组的首位，并在导航旁打开智能体栏；智能体澄清您的目标并将实际工作交给任务。
- **[助手连接 (MCP)](../../experimental/assistant-connections.md)** — 将 Codex、Claude 和其他助手连接到您的 Paperclip 组织，以便人员可以审查工作、委派任务并提供反馈。需要具有配置了公共 URL 的已认证实例。
- **Beta 技能** — 允许智能体固定 Paperclip 核心技能的 Beta 版本。关闭它会将每个智能体恢复为默认实时技能，而不会移除您保存的固定项。
- **[内置智能体](../../reference/api/built-in-agents.md)** — 显示 Paperclip 管理的内置智能体界面（内置名册徽章、**内置智能体** 选项卡以及内置智能体设置控件），并使内置智能体 API 可用。在配置 `briefs`、`learning` 或 `reflection-coach` 之前请开启它；关闭时，内置智能体路由将返回 `404 Not Found`。
- **[案例](../../reference/api/cases.md)** — 任务创建并迭代的持久性工作产品（博客文章、推文风暴……）。添加 **案例** 选项卡和智能体案例 API。关闭它会隐藏选项卡并阻止 API；现有案例数据会被保留。

## 托管部署的操作员控制

如果您为其他人运行 Paperclip——托管云、内部共享服务器——您可以塑造用户看到的设置界面以及默认值，而无需触及任何用户的数据。两个环境变量实现了这一点。两者均在启动时读取，在读取时应用，且 **从不持久化**：清除变量后，在用户未另行选择的地方，标准行为将恢复。当两者均未设置时，UI 和 API 的行为与本页面描述完全一致。

### 使用 `PAPERCLIP_HIDDEN_SETTINGS` 隐藏界面

将 `PAPERCLIP_HIDDEN_SETTINGS` 设置为逗号分隔的界面键列表，以从 UI 中移除。某些键还会使用 `403`（携带 `settings_operator_managed` 代码）对其变更 API 进行限制；其余仅隐藏 UI，因此智能体和集成继续针对底层路由工作。

您可以列出的键：

- **实例页面** — `instance.profile`、`instance.environments`、`instance.access`、`instance.experimental`、`instance.plugins`、`instance.adapters`。（实例常规页面是设置根，无法隐藏；请单独隐藏其部分。）
- **公司页面** — `company.members`、`company.invites`、`company.secrets`、`company.export`、`company.import`。隐藏 `company.import` 也会限制导入 API；其他公司键仅针对 UI。
- **公司子选项卡** — `company.secrets.vaults`、`company.secrets.proposals`（在保持密钥页面开启的同时隐藏一个选项卡）。
- **实例常规部分** — `instance.general.deploymentStatus`、`instance.general.censorUsernameInLogs`、`instance.general.backupRetention`、`instance.general.feedbackDataSharingPreference`、`instance.general.signOut`。字段支持的部分也会限制对该字段的写入；`deploymentStatus` 和 `signOut` 是只读 UI。旧的 `instance.general.keyboardShortcuts` 键不再存在——键盘快捷键始终开启——因此如果它仍在您的列表中，Paperclip 将忽略它并记录警告。
- **实验性开关** — `instance.experimental.<flagKey>` 用于任何单个开关，或使用 `instance.experimental` 隐藏整个页面。
- **所有实验性开关，现在及未来** — `instance.experimental.*`。通配符隐藏服务器自身功能目录中的每个开关，因此未来升级添加的开关也将以隐藏状态到达，无需更改您的环境。实验性页面本身仍可达。若要保留几个开关可用，请添加以 `!` 为前缀的例外，例如 `!instance.experimental.enableEnvironments`。

例如，这将在实验性页面上仅保留环境开关，并隐藏插件页面：

```sh
PAPERCLIP_HIDDEN_SETTINGS='instance.plugins,instance.experimental.*,!instance.experimental.enableEnvironments'
```

例外仅放宽通配符。如果您还明确列出某个开关，或隐藏整个 `instance.experimental` 页面，无论条目顺序如何，后者都将胜出——而没有通配符的例外不起作用。隐藏开关从不更改其值：设置保持其被设置的状态，设置 API 仍允许您读取它，但尝试更改它会返回 `403` 和 `settings_operator_managed`。早于通配符支持的图像忽略通配符及其例外，因此在滚动升级期间，请保留任何明确的每个开关条目，直到所有图像都升级到新版本。

未知键会被警告并忽略，而不是被拒绝，因此您可以将一份列表滚动到混合应用版本的集群中——早于某个键的图像仅保持该界面可见，而不是拒绝启动。

### 使用 `PAPERCLIP_SETTING_DEFAULTS` 覆盖默认值

将 `PAPERCLIP_SETTING_DEFAULTS` 设置为 JSON 对象，以替换所选实例常规设置的架构默认值——目前为 `feedbackDataSharingPreference`。例如：

```sh
PAPERCLIP_SETTING_DEFAULTS='{"feedbackDataSharingPreference":"allowed"}'
```

您的值在读取时替换架构默认值：任何仍处于默认状态的字段将解析为您的值，而用户的明确非默认选择始终胜出。解析是故障关闭的——格式错误的 JSON 或已知字段的无效值会阻止服务器启动，因为静默丢弃的策略默认值比大声失败更糟。未知字段名会被警告并忽略。

这两个控制是正交的：当您想要默认值 *且* 想要隐藏控件时，请将它们配对使用。
