# 内置技能

内置技能是随 Paperclip 基础套件发布的目录条目。它们与应用版本同步，可通过目录 API 浏览，并可在团队需要相应工作模式时安装到公司中。

目录机制请从[技能参考](../skills.md#3-app-shipped-catalog)开始了解。可选扩展请参阅[可选技能](./optional.md)索引。

## 文档

- [文档维护](./bundled/docs/doc-maintenance.md)——使项目文档与近期代码和功能变更保持一致。

## Paperclip 操作

- [任务分流](./bundled/paperclip-operations/issue-triage.md)——对过期、受阻、待审核或停滞的 Paperclip 任务分类，并选择下一步操作。
- [状态卡查询](./bundled/paperclip-operations/status-card-query.md)——创建 Paperclip 状态卡，并将卡片的自然语言提示编译为范围明确的搜索查询和初始摘要。
- [任务规划](./bundled/paperclip-operations/task-planning.md)——将已批准的计划转化为 Paperclip 任务，并明确负责人、依赖关系和验收标准。

## 产品

- [线框图](./bundled/product/wireframe.md)——生成低保真 UI 线框图，并以独立 SVG 文件交付。

## 质量

- [QA 验收](./bundled/quality/qa-acceptance.md)——定义可观察的验收标准，并开展有针对性的验证。

## 软件开发

- [GitHub PR 工作流](./bundled/software-development/github-pr-workflow.md)——准备、检查、更新 GitHub 拉取请求并沟通相关工作。
