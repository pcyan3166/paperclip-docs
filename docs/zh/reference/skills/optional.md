# 可选技能

可选技能是目录条目，团队可在需要基础内置技能之外的特定能力时安装。它们沿用与内置技能相同的目录安装、审计、更新和重置机制。

目录机制请从[技能参考](../skills.md#3-app-shipped-catalog)开始了解。基础目录请参阅[内置技能](./bundled.md)索引。

## 浏览器

- [智能体浏览器](./optional/browser/agent-browser.md)——使用受监督的浏览器进行验证、截图和 JavaScript 渲染页面检查。

## 内容

- [发布公告](./optional/content/release-announcement.md)——将版本变更整理为简洁、面向公众的公告文案。
- [简明英语](./optional/content/simplified-english.md)——使用 ASD-STE100 简明技术英语撰写面向用户的评论、计划和文档，让读者首次阅读就能理解。

## 财务

- [Ramp](./optional/finance/ramp.md)——在 Paperclip 的审批关卡和主机允许列表约束下，遵循 Ramp 官方智能体操作手册（入职、卡片和支出控制）。

## 产品

- [设计评审](./optional/product/design-critique.md)——检查产品或 UI 流程的清晰度、层级结构和执行风险。

## 研究

- [Last30Days](./optional/research/last30days.md)——跨 Reddit、X、YouTube 和网络搜索某一主题近期公开讨论。

## 软件开发

- [准备 MCP 集成](./optional/software-development/prepare-mcp-integration.md)——研究新的 MCP 或供应商集成，在获得针对确切修订版本的人工批准后，再为每个获批连接发布一个受治理的 Paperclip 连接器。
