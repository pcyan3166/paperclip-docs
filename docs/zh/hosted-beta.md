# 欢迎使用 Paperclip 托管版测试

创建一支 AI 智能体团队，让它们承担项目和持续性工作。Paperclip 为智能体提供云端工作区，并让你可以在一个地方分配工作、跟踪进度和审阅结果。

此托管版测试仅限受邀用户参加。

## 完成设置

1. **登录。** 打开邀请链接，使用 Google、GitHub 或电子邮件登录。请使用收到邀请的邮箱地址。
2. **创建组织。** 为组织命名。
3. **为首个智能体命名。** 首个智能体会帮助你规划工作并组建团队。输入名称，然后选择 **Next**。
4. **连接模型。** 选择 Claude 或 OpenAI，然后按提示连接订阅或 API 密钥。
5. **完成设置。** Review（检查）页面显示智能体已就绪后，选择 **Get started**。

## 开始委派工作

首个智能体会询问你想委派哪些工作。你可以让它采访你并提出计划，也可以选择 **I have a task in mind**（我已经有任务想法）。

你可以提供单项任务、持续性工作流或更大型的项目。说明期望结果并提供相关背景。组建团队时，可以添加智能体并连接它们所需的工具。

在任务中跟踪进度、回答问题并审阅结果。智能体请求审批时，请先检查拟执行的操作，再批准或要求修改。

请参阅[管理任务](https://docs.paperclip.ing/guides/day-to-day/issues/)和[跟踪智能体活动](https://docs.paperclip.ing/guides/day-to-day/dashboard/)指南。

## 帮助塑造 Paperclip 的未来

告诉我们哪些地方好用，尤其是哪些地方不好用。遇到卡住的情况时，请告诉我们你原本期待什么、实际发生了什么。你的反馈将帮助我们决定下一步改进方向。

你可以在[测试版专属 Discord](https://discord.gg/zTXFu6UR7)或产品内聊天中提问、分享反馈并获得支持。如果无法登录，请发送邮件至 [support@paperclip.ing](mailto:support@paperclip.ing)。

感谢你帮助我们构建 Paperclip。

## 常见问题

<details class="accordion">
<summary>连接 Claude 或 OpenAI 后，哪些内容会一并带入？</summary>
<div class="accordion-body">

连接 Claude 或 OpenAI 后，Paperclip 可以使用你的账户运行智能体。它不会导入你已有的对话、本地文件、技能或 MCP 连接。请添加智能体所需的背景信息和连接。

</div>
</details>

<details class="accordion">
<summary>关闭浏览器后，我的智能体还会继续工作吗？</summary>
<div class="accordion-body">

会。智能体在托管环境中运行，因此它们工作时，你的电脑可以关机或离线。任务仍可能因等待输入、审批或达到用量限制而暂停。

</div>
</details>

<details class="accordion">
<summary>托管版测试免费吗？</summary>
<div class="accordion-body">

免费。测试期间我们不会对托管服务或智能体环境收费。模型提供商的费用和用量限制仍然适用。

</div>
</details>

<details class="accordion">
<summary>我应该预期多少模型用量？</summary>
<div class="accordion-body">

用量取决于模型、任务、上下文以及智能体运行频率。计划任务也会消耗提供商的套餐额度或 API 余额。

请查看提供商账户中的账单和订阅限制。Paperclip 的支出总额不会显示订阅套餐剩余额度。

请参阅[成本与预算](https://docs.paperclip.ing/guides/day-to-day/costs/)以及[心跳与例程](https://docs.paperclip.ing/guides/projects-workflow/routines/)，了解费用和智能体的运行时机。

</div>
</details>

<details class="accordion">
<summary>可以连接我的工具和代码仓库吗？</summary>
<div class="accordion-body">

请在 **Connectors** 中查看可用连接并授权访问。请在托管组织中设置连接；本地安装中的连接不会自动带入。

</div>
</details>

<details class="accordion">
<summary>可以导入现有公司吗？</summary>
<div class="accordion-body">

此测试版暂不支持导入公司。请创建新组织，并为其设置智能体和连接。

</div>
</details>

<details class="accordion">
<summary>现有文档是否适用于托管版测试？</summary>
<div class="accordion-body">

产品功能和工作流请参阅[文档](https://docs.paperclip.ing/)。自托管安装和运行时设置部分可以跳过——这些由我们负责管理。

</div>
</details>
