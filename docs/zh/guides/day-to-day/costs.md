# 成本与预算

**注意：** AI 智能体会发起真实的 API 请求并产生费用。每次心跳、任务处理，以及读取或撰写评论，都可能通过 Anthropic、OpenAI 等提供方发送和接收文本，并按 token 收费。这不是 Paperclip 收取的费用，而是你直接支付给 AI 提供方的费用。请在智能体开始持续运行前阅读本指南。

Paperclip 的预算系统让你设定支出上限，并自动执行，避免超出允许范围。相关功能位于侧栏的 **审计（Audit）** 页面。页面包含 **活动（Activity）**、**运行（Runs）**、**成本（Costs）**、**预算（Budgets）** 和 **时间线（Timeline）** 标签。本指南介绍成本和预算。

成本标签包含 **总览（Overview）**、**提供方（Providers）**、**计费方（Billers）**、**财务（Finance）**、**决策（Decisions）** 和 **快速响应（Fast responses）** 视图，并共享日期范围选择器和顶部指标。预算标签管理限额以及达到限额后产生的事件。旧版 `/costs`、`/budgets` 链接仍会重定向到审计页面。

## 成本如何计算

每次智能体心跳都会产生 API 请求，把身份、任务和指令等上下文发送给 AI 提供方，再接收回答和后续操作。费用通常依输入与输出 token 数计算。Paperclip 记录智能体、模型、token 数量和费用，并按智能体汇总到 UTC 日历月（每月 1 日重置）。Token 大致相当于一个词，但实际是文本片段；繁忙的编码或写作智能体可能每月处理数十万 token，费用会随模型和上下文而显著变化。

### 为什么费用可能低于 token 单价推算

智能体会在每次心跳重复发送身份、常驻指令和任务上下文。提供方可缓存重复提示，并以较低价格计费。提供方视图会把缓存输入 token 单独列出。Paperclip 记录提供方实际收取的缓存折扣后费用；适配器若单独报告折扣金额，则该金额用于成本账本、预算和汇总。通常应把页面显示的金额视为实收费用，并与 token 数一起解读。

### 估算、未定价和待入账费用

- **估算（Estimated）**：提供方未报告价格，但 Paperclip 根据已知模型费率和 token 数推算；相关行会标为“估算”或“部分估算”，实际账单可能略有差异。
- **未定价（Unpriced）**：有 token 使用记录，但无可靠价格。例如 CLI 使用非 OpenAI 或 OpenRouter 的 OpenAI 兼容端点时，Paperclip 不会擅自套用 OpenAI 费率。未知金额不会当作 `$0`。
- **等待记账（Awaiting accounting）**：运行已结束，但费用尚未记录。Paperclip 会在取得本地 CLI 保存的用量后完成记账，即使运行中断或超时也适用。

总览指标下方可能出现“若干运行费用不可用”等提示。提示消失前，应把显示的金额理解为**已知支出**。点击提示可按智能体查看最近记录及原因：成本不可用、未报告模型、计费类别未知、正在接收用量、最终用量不可用，或已准备好记账。需要修改智能体模型或 AI 连接时，可在智能体配置中处理；准备好记账的条目可点 **重试费用记录（Retry cost recording）**，这只补记账，不会重跑智能体。若费用无法定价或仍在等待，预算也可能暂停新工作，详见[支出不确定时](#支出不确定时)。

非 API 或订阅的用量（如积分或固定价格方案）会在指标下方单列，但仍计入推理总量。订阅费、充值、发票调整和退款等账户级费用不属于单次 API 请求，会单独记录在财务账本。

## 成本标签：日期范围与指标

日期范围按钮包括 **本月至今（Month to Date）**、**7 天**、**30 天**、**今年至今（Year to Date）**、**全部时间（All Time）** 和 **自定义（Custom）**。本月至今和今年至今从 UTC 午夜起算；自定义范围需填写开始和结束日期。多数视图在范围未完整填写前不会加载。

顶部有五项指标：

- **API 支出（API spend）**：范围内按量付费 API 费用及 token 数，可能带估算标签；没有可靠价格时显示 `—`。
- **订阅（Subscriptions）**：连接的 AI 订阅月费，以及本范围内经订阅使用的 token 数。
- **预算（Budget）**：预算事件数；本月至今时显示使用比例，其他范围显示月度限额；未设上限时显示 **开放（Open）**。
- **已记录费用（Recorded charges）**：范围内账户级账本净额及借贷明细。
- **财务事件（Finance events）**：事件数及仍未与发票核对的估算借项。

如果账本包含多种货币，指标仅汇总美元，其他货币单列，不换算。订阅指标展示当前月费，不受所选日期范围影响。

### 订阅

Claude、ChatGPT/Codex 或 Grok 订阅的运行通常没有逐次 API 费用，但仍有月费。Paperclip 根据 AI 连接识别订阅账号；多个智能体共用同一付费席位时只计一次，不同席位分别计算。详情显示账号所有者、提供方、方案、月费、用量和使用该账号的智能体。标为“估算·税前”的价格来自公开价；无法确定具体方案价格时显示“价格未知”。

可通过 **编辑价格（Edit price）** 填写方案、计费周期金额、币种（USD、EUR、GBP、CAD、AUD、CHF）、月付/年付和跟踪状态。年费会除以 12。保存后新价格用于之后的记录，历史价格保留。结束跟踪不会取消提供方订阅；取消后应自行将状态设为已结束。个人账号可自行改价，共享账号需要管理 AI 连接的权限。若多个条目实际属于同一订阅，可用 **与另一个账号属于同一订阅？（Same subscription as another account?）** 链接账号，避免重复计费并合并用量。

订阅费用属于账户级费用，不计入智能体预算，也不作为财务事件；取消连接本身不会停止月费。若订阅账号另有超额用量费用，会在指标下方单独说明。

## 总览

**总览（Overview）** 是成本标签的默认视图，结合顶部指标查看公司支出状况。

- **按智能体（By agent）**：列出智能体费用、估算状态、输入/缓存/输出 token、API 和订阅运行数。展开行可按提供方、模型、计费类型查看明细。后台决策等无归属智能体的费用列为 **Paperclip 服务（Paperclip services）**。
- **按用户（By user）**：汇总每位成员对应的运行数、输入/输出 token 和成本。无归属用量列为 **未归属（Unattributed）**；全部未定价时成本显示 `—`，而不是 `$0`。
- **按项目（By project）**：将由项目任务触发的运行费用归入该项目，其他费用列为未归属。
- **活动预算事件（Active budget incidents）**：显示最多两项达到警告或硬上限的事件，可选择保持暂停或提高预算并恢复。支出不确定导致的暂停会标明记账未完成。
- **财务账本（Finance ledger）**：列出借项、贷项、净额和估算费用；详见“财务”视图。

## 提供方

**提供方（Providers）** 按实际执行推理的厂商（Anthropic、OpenAI、Google 等）拆分支出。可选 **所有提供方（All providers）** 汇总或查看单一提供方。卡片按模型列输入、缓存输入、输出 token 和费用，也显示当前自然周支出，以及在本月至今范围内的公司预算占比与超额风险。

连接 Anthropic 或 OpenAI 订阅后，卡片还会显示订阅用量窗口。每个账号使用其自身已保存的登录信息，不依赖运行 Paperclip 的机器当前登录账号。页面显示窗口名称、已用比例和重置时间。若读取暂时失败，会保留最近一次有效读数并说明；无历史数据或连接/登录过期时，会提示不可用并清除旧读数。窗口支出用于观察费用在配额窗口内的分布。

## 计费方

**计费方（Billers）** 回答“谁向我收费”，而提供方回答“谁执行了推理”。二者可能不同，例如经由网关或转售商付费。卡片显示范围内费用和 token、本周费用、占公司月预算比例，以及该计费方所支付的各模型提供方明细。可用于与月末发票核对，必要时进一步比较提供方、模型和时间戳。每笔成本事件都标记提供方和计费方；简单设置下两者相同，复杂账务则可借此区分。

## 财务

**财务（Finance）** 是账户级账本，记录订阅费、发票核对、充值、退款和调整等非单次推理费用。摘要卡显示借项、贷项、净额和估算金额；按计费方卡片显示各厂商的借贷金额和事件数；近期财务事件按时间列出类型、金额、计费方和是否为估算；事件类型卡可按订阅扣费、充值或调整等分类。

发票是最终依据。发票导入核对前，订阅日费用可能按方案价和周期估算；导入真实发票后，条目会成为权威金额。美元总计之外的币种会分别展示，不使用汇率转换。提供方 API 成本报告会单独显示，不加进已记录费用，以免与发票和运行估算重复；导入发票后可逐项比较并更正差异。相关接口见[成本记账 API](../../../reference/api/costs.md#accounting)。

## 决策模型与快速响应

一些可选功能会用小型快速模型判断“是否与账单有关”或“该交给哪个团队”，而不是唤醒完整智能体。此类调用在 **决策（Decisions）** 视图中列出；它不同于需要人作决定的[决策队列](./decisions.md)。

公司可在 **公司设置（Company Settings）→ 常规（General）** 的 **决策模型（Decision model）** 区域选择一个共享 OpenAI 或 OpenRouter API 连接；若管理员启用了实验性快速响应，该设置可能位于“连接”中。仅共享 API 密钥可用，不支持个人账号、订阅或自定义端点。选择连接后保存并运行测试；测试会产生真实 API 费用，答案只显示一次且不保存，用量会记录。关闭 **启用决策（Enable decisions）** 只会停止新请求，不会删除已发送请求。背景决策是否使用公司费用由相应选项控制。

决策视图按日期范围列出最近最多 100 项请求：时间与功能、责任人、任务、模型、状态、耗时、token 数和成本（已报告、估算或未知）。Paperclip 不保存问题、输入或答案，只保存元数据。决策费用按普通支出计入公司、相关智能体和项目预算；超时请求在费用结算前会保留预算占用。**快速响应（Fast responses）** 是实验性功能，开启后小模型会在智能体开始工作时发出简短确认；成本视图也会列出其连接来源。

## 预算标签

打开 **审计（Audit）→ 预算（Budgets）**。预算使用独立周期，不受成本日期范围影响。Paperclip 提供三个作用范围：

- **公司预算**：全公司每月总上限。
- **智能体预算**：每个智能体的独立月度上限，即使公司尚有余额，达到上限的智能体也会暂停。
- **项目预算**：执行项目的终身上限，可在项目自己的预算标签中设置。

预算控制台显示活动事件、待审批覆盖、暂停智能体和暂停项目数量。预算大致分为正常、警告（常见阈值为 80%）和硬上限（100%）：警告不应导致智能体暂停；达到硬上限时会自动暂停后续心跳。月度预算在每月 1 日 UTC 重置。自动暂停不会丢失未完成任务；恢复后会继续处理。

若某个运行已完成但费用仍等待记账，Paperclip 会在计算后再开放新工作；若使用量未定价，默认也会阻止新工作，避免在支出未知时超限。预算卡片会说明待记账或未定价数量。可在 **高级设置（Advanced settings）** 取消 **用量无可靠价格时阻止新工作（Block new work when usage has no reliable price）**，但这样会在未知金额下继续运行；否则先通过记账接口补充费用。

活动事件卡展示范围、配置上限和实际支出。**保持暂停（Keep paused）** 会保留暂停状态；**提高预算并恢复（Raise budget & resume）** 要求输入高于已花费金额的新上限，并立即恢复。待记账或需要拦截的未定价用量未解决时不能提高预算。两种操作都会记录在审计历史。

预算策略卡显示范围、周期、状态（健康、警告、硬上限、已暂停）、已用金额与比例、剩余额度、待记账和未定价用量，以及 **预算（USD）** 输入框。设置为 `0` 会关闭策略。高级设置还提供是否阻止未知费用，以及 **每次运行预留（Reserve per run）**：启动前预留预算，避免多个并发运行一起突破上限；未完成运行会占用预留额度。预留只控制何时可开始，实际费用仍可能更高。

公司预算可在组织预算卡中设置；尚无策略时可通过 API 创建。智能体月度预算可在其卡片中更新，或使用 CLI/API；新建智能体流程不一定自动设置预算。项目预算在项目的 **预算（Budget）** 标签中设置，为终身上限。预算卡可在健康、警告和暂停状态下查看。提高暂停智能体预算后，只要记账完整便会立即恢复；否则等到新 UTC 月份开始会自动重置。若不希望月初自动恢复，请手动暂停智能体。

## 监控支出

仪表板的 **本月支出（Month Spend）** 卡片显示当月金额及公司预算占比；发生超限时会显示事件和暂停智能体数量。点击卡片可进入成本总览。展开“按智能体”行可查看其模型和提供方费用；智能体详情中的审计区域也可直达运行记录和预算。

跨智能体分析时，在审计成本中选择对应视图：总览查看整体，提供方/计费方核对厂商，财务核对发票，决策/快速响应查看小模型调用，预算标签管理硬性限额。

## 节省成本的建议

- CEO 等需要战略推理的智能体使用能力更强的模型；执行常规写作、数据处理和搜索的工作智能体可使用更快、更便宜的模型。
- 不需要快速响应的后台智能体应减少心跳频率；例如每小时运行比每 15 分钟运行少约四分之三的调用。
- 让任务说明简洁、具体，并写清完成标准，降低每次心跳重复读取的上下文量。
- 若业务不需全天运行，可在非工作时段暂停智能体。
- 新智能体运行几次后查看单次成本，检查长上下文、过多工具调用或不合适的提示词。
- 用量稳定且在配额内时，可比较订阅与按量 API 费用，并通过配额窗口确认余量。
- 定期导入真实发票，及时用权威账单替换估算并发现价格变化。
