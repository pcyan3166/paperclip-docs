# 成果

智能体工作时不只会留言，也会生成文档、图片、视频、CSV 导出文件，或向任务附加文件。这些产出统称为**成果（artifacts）**。成果页面汇总整个公司的工作产出，无需逐个打开任务查找。页面内容按公司隔离，切换公司后会显示对应公司的成果。

## 什么算成果

- **文档**：智能体在任务中创建或修订的计划、简报、报告等；系统管理的文档不会显示。
- **附件**：人员或智能体直接附加到任务的图片、PDF、视频、CSV、JSON 等文件。
- **工作产出**：智能体作为任务正式结果提交的内容，也包括指向附件的产出。

每项成果都带有来源任务、所属项目（若有）、创建智能体和最近更新时间，并可直接跳回任务中的对应位置。

## 打开与筛选成果

从左侧栏打开 **成果（Artifacts）**。默认按任务分组，并按最近更新时间排序；向下滚动可加载更多。没有成果时，页面会提示任务附件会显示在这里。

可按 **全部（All）**、**图片（Images）**、**视频（Videos）**、**文档（Documents）**、**文本（Text）** 或 **文件（Files）** 筛选。搜索框会匹配成果标题、摘要和来源任务；搜索条件也会保存在网址中，方便收藏或分享。

## 按任务分组

使用筛选器旁的叠层方块按钮设置分组方式：

- **任务（Task）**：按生成成果的单个任务分组（默认）。
- **父任务（Parent task）**：将子任务成果归入顶层父任务。
- **无（None）**：取消分组，显示平铺列表。

分组卡片显示任务、成果数量和预览。点击卡片可查看该组；**所有分组（All stacks）** 返回总览。筛选条件和搜索会在组内保留，分组选择也会写入网址。

## 预览成果

文档卡片显示易读的文本摘要；文本文件（如 JSON、XML）显示内容预览；图片和视频显示视觉预览；其他文件显示类型并提供打开或下载入口。每张卡片都链接回来源任务。

任务属性面板中的 **成果（Artifacts）** 标签则按运行记录整理该任务的产出，最新运行排在前面，并显示执行智能体。卡片类型包括：

| 类型 | 显示内容与操作 |
|---|---|
| **拉取请求（Pull request）** | PR 编号、仓库、分支、状态、检查结果和变更；使用 **打开拉取请求（Open pull request）**。 |
| **提交（Commit）** | 短 SHA、仓库、分支和变更；使用 **查看提交（View commit）**。 |
| **文档（Document）** | 文档预览；使用 **阅读文档（Read document）** 展开。 |
| **图片/视频** | 图片预览或视频截图；可打开媒体查看器。 |
| **链接预览（Link preview）** | 智能体发布的预览网址及其图片；使用 **打开链接（Open link）**。 |
| **数据（Data）** | CSV 文件；使用 **预览数据（Preview data）** 加载表格或下载原文件。 |
| **文件（File）** | 其他类型文件及大小；可打开或下载。 |

图片和视频共用媒体查看器，可用 **上一项/下一项（Previous/Next）** 或方向键浏览；按 Esc 关闭。CSV 卡片预览需主动点击，支持最大 1 MiB 的文件，最多显示 200 行、50 列；无法预览时仍可下载。Markdown 和纯文本附件可通过 **在标签页中打开（Open in tab）** 在侧栏新标签页阅读；标签页会复用。Markdown、CSV 和 HTML 可在 **已渲染（Rendered）** 与 **原始内容（Raw）** 之间切换。若分支没有远程链接，会明确显示 **分支 · 无远程链接（Branch · no remote link）**；可展开 **显示详情（Show details）** 查看提供方、状态和更新时间。异常成果会带有 **异常（Unhealthy）** 标签。

此标签为只读，不能在这里上传或删除成果。启用旧版 **经典任务界面（Classic Task Interface）** 时，任务不提供成果标签，附件仍显示在任务页面的 **附件（Attachments）** 区域。

## CSV 表格与 HTML 报告

在文件标签页或工作区查看器中打开 CSV 时，内容会以表格呈现：首行作为列标题，行带编号，滚动时标题固定，并显示行列数。最多显示 500 行、100 列；更大的文件只显示开头部分，可下载获取完整文件。**原始内容（Raw）** 可查看原文，也适合排查引号格式错误。此功能与卡片上的“预览数据”不同，后者是在卡片中加载较小预览。

HTML 附件及工作区中的 `.html` / `.htm` 文件会以可交互页面打开，也可切换到原始内容。报告运行在受限沙盒中：脚本只能控制报告自身，无法读取 Paperclip 会话、Cookie 或存储，也无法访问应用其他部分。网络请求、远程脚本和资源、表单、弹窗及跳转都会被拦截。因此报告必须自包含，脚本和样式需内嵌，图片和字体需使用 `data:` URL；从 CDN 加载的图表库需先嵌入。

## 应用内文件查看器

任务工作区中的真实文件可直接在应用内查看，无需下载。点击文件会打开侧滑查看器：文本和代码文件（如 `.ts`、`.py`、`.json`、`.md`、`.csv`、`.yaml`、`.sql`）带行号显示；带行号链接会自动滚动并高亮。Markdown 默认渲染，CSV 显示为表格，HTML 在受限沙盒中打开。PNG、JPG、GIF、WebP 图片会直接预览，MP4、MOV、WebM、M4V 视频提供播放器。查看器可复制内容或链接。

文件过大、类型不支持预览、路径可能含敏感信息（如 `.env`、密钥或凭据），或工作区已清理/位于不支持内嵌预览的远程主机时，查看器会说明原因。

智能体在 Markdown 或评论中用行内代码提及工作区路径时，Paperclip 会把它显示为可点击文件标签。支持 `path/to/file.ext`、`:42` 行号、`:42:3` 行列号、`#L42`、`#L42C3`；以斜线结尾的目录路径会打开文件浏览器。侧边文件树支持展开、导航和按名称搜索，并跳过 `.git`、`node_modules`、构建产物和凭据目录等敏感或嘈杂内容。可下载的文件行会显示下载按钮。

## 对文档发表评论

在任务属性面板的 **计划（Plan）** 或 **成果（Artifacts）** 标签中选中文本，会出现 **评论（Comment）** 操作；也可按 ⌘⇧M（Windows/Linux：Ctrl+Shift+M）打开编辑器，⌘↵ 发布。此功能支持问题、例程和案例文档。

评论会在文档旁打开串接讨论面板：桌面端为侧栏，手机端为底部面板。人员和智能体都可以评论与回复，智能体作者会明确标示。每个讨论串最初为 **未解决（open）**；点击 **解决（Resolve）** 后会淡化显示，也可用 **重新打开（Reopen）** 恢复。文档标题中的评论计数标签显示未解决评论数，点击可打开讨论面板。

文档修订时，Paperclip 会尝试将批注锚定到原文。定位可靠时状态为 `active`；若文字移动或改变，批注会标为 `stale`；若原文完全消失，则为 `orphaned`。讨论记录仍会保留。每个讨论串都可通过 **复制链接（Copy link）** 获取直达链接。

## 快速理解

- **成果页面**：公司所有任务的产出总览。
- **类型筛选与分组**：按媒体类型筛选，按任务或父任务整理。
- **成果卡片**：就地预览并返回来源任务。
- **文件查看器**：在应用内阅读工作区文件并浏览目录。
- **任务成果标签**：查看单个任务的运行产出。
- **文档评论**：针对计划或成果文档中的具体段落进行可分享的讨论。

想了解成果背后的工作时，点击卡片链接回到来源任务即可。另见[问题页面](./issues.md#tabs-in-the-properties-panel)。
