# 制品

智能体工作时留下的不只有评论，还会生成各种成果：起草的文档、生成的图像、渲染的视频、CSV 导出文件，以及附加到问题中的文件。这些可见产出称为**制品（artifacts）**。**Artifacts** 页面集中显示整个公司的所有制品，你无需逐个打开问题查找。

可以把它看作公司已完成和正在进行的工作成果架。只要是智能体完成任务时生成的内容，就会显示在这里。

---

## 哪些内容属于制品

制品是智能体在工作过程中生成的内容。Paperclip 会把三种输出统一放进 Artifacts 页面：

- **文档（Documents）**——智能体在问题上撰写或修订的键控文档，例如计划、简报或报告。系统管理的文档会被过滤，因此你只会看到真正的交付成果。
- **附件（Attachments）**——直接附加到问题的文件，可以由智能体或人员添加，包括图像、PDF、视频、CSV、JSON 等。
- **工作成果（Work products）**——智能体作为任务正式输出交付的结果，也包括指向某个附件的成果。

每项制品都会附带理解它所需的上下文：所属问题、所属项目（如果有）、创建它的智能体，以及最近更新时间。每张卡片都直接链接到源问题的确切位置，因此只需点击一次即可从成果架返回来源。

制品按当前查看的公司划分。切换公司后会显示该公司的成果架。

---

## 打开 Artifacts 页面

从左侧边栏打开 **Artifacts**。默认情况下，页面会按组（下文称为堆栈）显示公司制品，并按最近更新时间从新到旧排序；向下滚动时会继续加载。

没有可显示内容时，页面会明确提示。例如，新公司会显示 “No artifacts yet. Outputs attached to issues will appear here.”（尚无制品。附加到问题的输出会显示在这里。）智能体开始完成工作后，成果架会自动填充。

---

## 按类型筛选

一行类型筛选器可将成果架限定为某一类输出：

- **All**——全部内容（默认）。
- **Images**——图像。
- **Videos**——视频。
- **Documents**——文档。
- **Text**——文本。
- **Files**——除图像、视频和类文本文件之外的所有文件。

选择筛选器即可聚焦查看。例如，想审阅智能体生成的所有视频时，可以切换到 **Videos**；想集中查看文字交付成果时，可以选择 **Documents**。

页面顶部还有搜索框。输入几个关键词后，列表会缩小到标题、摘要或来源问题匹配的制品；搜索条件也会写入页面 URL，因此筛选后的视图可以轻松分享或收藏。

---

## 堆栈：按任务分组的制品

单个任务可能生成多项制品，大型工作也可能拆分为许多子任务。为了避免卡片变成一整面无法区分的墙，Artifacts 会将输出分组成**堆栈（stacks）**。

使用分组控件（筛选器旁边的叠层方块按钮）选择制品的归组方式：

- **Task**——按生成制品的单项任务分组。这是默认视图。
- **Parent task**——将子任务的制品归到顶层父任务下，让同一大型计划的输出出现在一个堆栈中。
- **None**——关闭分组，以平铺网格显示每项制品。

在分组视图中，每个堆栈是一张卡片，显示所属任务、制品数量以及前几项制品的小型预览。点击堆栈可只查看该任务的制品；**All stacks** 链接会返回总览。进入和离开堆栈时，当前类型筛选和搜索条件都会保留；分组选择也会保存在 URL 中，因此视图可以分享。

---

## 查看制品

卡片旨在让你无需先下载，就能快速理解制品内容：

- **Documents** 显示易读的文本预览——Markdown 格式会简化为可读的纯文本，便于快速了解大意。
- **Text files**（以及 JSON、XML 等类文本文件）显示简短的内容预览。
- **Images and videos** 显示视觉预览，因此生成的视频会在卡片上显示缩略图，而不是只出现一行匿名文件名。
- **Other files** 会以卡片显示类型，并可打开或下载。

制品来自真实文件时，卡片会提供内嵌打开或下载方式。每张卡片还会深度链接到源问题，因此你可以直接回到完整上下文——包括对话、生成该制品的运行，以及相关工作。

## 从任务中查看制品

Artifacts 页面是公司级成果架。有时你已经在某个任务中，只想查看**该任务**产生的内容，而不想先返回成果架再进行筛选。

任务的属性面板中有一个 **Artifacts** 标签，专门用于此目的。输出按生成它的运行分组，最近运行排在前面，并显示运行该任务的智能体名称。每项输出都有一张完整宽度的卡片，样式与内容类型相匹配，让你可以一眼区分合并的拉取请求和草拟的报告：

| 卡片 | 显示内容 | 打开方式 |
|---|---|---|
| **Pull request** | PR 编号、仓库、源分支和目标分支、状态（**Open**、**Draft**、**Merged** 或 **Closed**）、检查状态（**Checks passed**、**Checks failed**、**Checks pending**），以及更改的行数和文件。 | **Open pull request** |
| **Commit** | 短 SHA、仓库、分支和更改的行数。 | **View commit** |
| **Document** | 智能体撰写的文档预览。 | **Read document** 会展开文档；**Close document** 会将其折叠回去。 |
| **Image** | 图像本身。 | **View image** 会打开图库查看器。 |
| **Video** | 视频片段中的一帧。 | **Open video** 会播放视频。 |
| **Link preview** | 智能体发布的预览 URL，例如已部署的预览站点；如果有预览图片，也会显示图片。 | **Open link** |
| **Data** | CSV 文件。只有在你请求时才会加载表格。 | **Preview data** 会将前几行加载到表格；**Download file** 会保存原文件。 |
| **File** | 其他所有类型的文件，并显示类型和大小。 | **Open file** 或下载。 |

还有一些细节需要了解：

- **图像和视频共用一个图库。**打开任务中的图像或视频卡片，即可在媒体查看器中审阅。存在多个项目时，可使用 **Previous** 和 **Next** 或键盘左右方向键切换。视频带有播放控件；标题栏提供下载，按 **Esc** 可关闭查看器。
- **CSV 预览按需加载。**点击 **Preview data** 可为不超过 1 MiB 的文件加载表格。预览最多显示 200 行数据、最多接受 50 列。文件过大或不支持预览时，界面会解释无法加载的原因，并继续提供下载；获取预览失败时，可重试。
- **文本文件会在标签页中打开。**Markdown 和纯文本附件会显示 **Open in tab** 按钮。点击后，文件会在同一侧边面板的标签页中打开，对话仍可见。点击对话中的文本附件也会打开同一个标签页；之后打开其他文件时会重复使用该标签页。下载按钮始终可用于获取原文件。
- **Markdown、CSV 和 HTML 会以渲染方式打开。**下载按钮旁边的眼睛图标（**Rendered**）和代码图标（**Raw**）可在格式化视图和源文件之间切换。CSV 会像[以表格查看 CSV 文件](#csv-files-as-tables)一节所述那样以表格打开；HTML 报告会像 [HTML 报告](#html-reports)一节所述那样以可交互页面打开。
- **没有远程链接的分支会明确标记。**智能体记录了分支但未提供远程 URL 时，卡片会显示 **Branch · no remote link**，不会假装存在可点击的目标。使用 **Show details** 可查看提供程序、状态和最近更新时间。如果智能体保存了描述，该内容会显示在 **Saved description** 下。
- **不健康的输出会显示标记** **Unhealthy**，避免损坏的预览链接被误认为仍然可用。

该标签为只读，用于快速回答“此任务产出了什么？”，不能在此上传或删除文件。

实现参考：[artifact cards](https://github.com/paperclipai/paperclip/blob/a6306ba606eb87c89b9ef0344e9fe8e0025580f9/ui/src/components/artifacts/IssueArtifactCard.tsx)、[CSV preview limits](https://github.com/paperclipai/paperclip/blob/a6306ba606eb87c89b9ef0344e9fe8e0025580f9/ui/src/lib/artifact-card-data.ts) 和 [media gallery](https://github.com/paperclipai/paperclip/blob/a6306ba606eb87c89b9ef0344e9fe8e0025580f9/ui/src/components/ImageGalleryModal.tsx)。

> **注意：**如果实例启用了旧版布局 **Classic Task Interface**（位于 **Settings → Experimental** 的 **Legacy** 下），任务中不会显示 Artifacts 标签——附件仍位于任务页面的 **Attachments** 区域。参见[实验功能](../../experimental/overview.md)。

无论使用哪种布局，Artifacts 页面仍是跨任务和项目查看全部内容的统一入口。有关其他属性面板标签，请参阅[问题](./issues.md#tabs-in-the-properties-panel)。

<a id="csv-files-as-tables"></a>
### 以表格查看 CSV 文件

在标签页或工作区文件查看器中打开 CSV 文件时，文件会以表格而非纯文本显示。第一行会作为列标题，各行会显示行号；滚动时表头会固定。表格上方的信息条会显示文件的行数和列数。

表格最多显示 500 行和 100 列。文件超过限制时，界面会说明并显示开头部分。下载文件即可获取完整内容。切换到 **Raw** 可查看原始文本；如果文件中有引号字段损坏，也应在此处检查。

这与 Artifacts 标签中 CSV 卡片上的 **Preview data** 按钮不同；后者会直接在卡片中加载更小的预览。

<a id="html-reports"></a>
### HTML 报告

智能体经常会将带图表、表格或筛选器的报告作为单个 HTML 文件交付。HTML 附件和工作区中的 `.html` / `.htm` 文件会以渲染后的形式打开，因此你可以直接在 Paperclip 中使用报告。切换到 **Raw** 可查看源代码；下载可获取原始文件。

报告在受限沙盒中运行。其脚本可以控制报告页面本身，但不能读取你的 Paperclip 会话、Cookie 或存储，也不能操作应用的其他部分。网络请求、远程脚本、样式、图像和字体、表单、弹出窗口以及离开当前页面的导航都会被阻止。因此，报告必须自包含：将脚本和样式内联，并将图像和字体嵌入为 `data:` URL。依赖 CDN 加载图表库的报告无法正常工作，除非先将该库嵌入。

实现参考：[CSV table](https://github.com/paperclipai/paperclip/blob/1b4c803816e82b0265c8422e1a804327a7ed8c54/ui/src/components/CsvPreview.tsx) 和 [HTML sandbox policy](https://github.com/paperclipai/paperclip/blob/1b4c803816e82b0265c8422e1a804327a7ed8c54/ui/src/lib/html-preview.ts)。

## 在应用内查看器中读取文件

如果制品是来自问题工作区的真实文件，你可以不下载就直接阅读。点击文件后，Paperclip 会打开**应用内文件查看器（in-app file viewer）**——一个侧滑面板，会在应用中就地加载文件内容。

显示方式取决于文件类型：

- **文本和代码文件**（`.ts`、`.py`、`.json`、`.md`、`.csv`、`.yaml`、`.sql` 等）会作为带行号的源内容打开。链接指向特定行时，查看器会滚动到该行并高亮显示。
- **Markdown 文件**默认以渲染后的形式打开，可通过右上角切换按钮在**渲染视图**和**原始源文件**之间切换。**CSV 文件**提供相同的切换功能，并以表格打开；**HTML 文件**则在沙盒中以可交互页面打开。参见[以表格查看 CSV 文件](#csv-files-as-tables)和 [HTML 报告](#html-reports)。
- **图像**（`.png`、`.jpg`、`.gif`、`.webp`）和**视频**（`.mp4`、`.mov`、`.webm`、`.m4v`）会内嵌预览——图片直接显示，视频则提供带控件的播放器。

查看器还提供一些便捷操作：**copy contents** 按钮可复制文件文本（或原始数据）；**copy link** 按钮可复制直接指向查看器中该文件的链接。

某些文件无法预览时，查看器会明确说明原因，而不是静默失败。例如，文件过大；文件类型不支持文本、图像或视频预览；路径因可能包含敏感数据而被屏蔽（例如 `.env` 文件、密钥或凭据会被有意禁止访问）；或者问题工作区已清理，或位于暂不支持内嵌预览的远程主机上。

## 智能体文本中的内嵌文件链接

智能体不只会附加文件，也会在文字中**提及**文件。智能体在 Markdown 或评论中引用工作区文件时，Paperclip 会将引用转换为可点击的**文件标记（file chip）**，而不是普通文本。点击标记后，同一个应用内文件查看器会打开对应文件。

此功能适用于行内代码中的路径，也适用于指向文件特定位置的路径。以下写法都会转换为文件标记：

- `path/to/file.ext`
- `path/to/file.ext:42`（跳转到第 42 行）
- `path/to/file.ext:42:3`（第 42 行、第 3 列）
- `path/to/file.ext#L42` 和 `path/to/file.ext#L42C3`

以斜杠结尾的路径，如 `path/to/folder/`，会变成文件夹标记，点击后在浏览器中打开对应目录。这样一来，智能体对“修改了什么”的说明会直接链接到相关文件，无需复制粘贴路径或在工作区中查找。

## 浏览工作区文件

有时你想浏览文件，而不是打开某个特定文件。查看器侧边包含**文件浏览器**：它以树形结构展示问题工作区中的文件和文件夹，可展开、导航并按名称搜索。选择文件后，文件会在旁边的同一查看器面板中打开；你可以拖动分隔线调整文件树宽度。

浏览器只显示安全且可预览的文件，并跳过 `.git`、`node_modules`、构建输出和凭据目录等杂乱或敏感目录，让你看到的是实际工作成果，而非后台文件。如果工作区尚未创建或已被清理，浏览器会说明情况，不会只显示空树。

文件可下载时，每行都会显示**下载按钮**。点击即可将文件保存到本机。这是在没有终端访问权限时，从云端或沙盒工作区取出成果最快的方式——例如分享报告、检查生成的图像，或从隔离环境中取出构建产物。

## 评论文档

有些制品不只是供人阅读——你可能还想逐行反馈。智能体交付书面文档（任务中的 **Plan** 或 **Artifact** 文档）后，你可以像在 Google Docs 中一样直接对文本添加行内评论。选择你要回应的句子，附上说明，并在该位置开始讨论。

### 对一段文字发表评论

打开任务属性面板中的 **Plan** 或 **Artifacts** 标签，并选择要评论的文字。选区旁会出现 **Comment** 操作；点击它，或按 **⌘⇧M**（Windows 和 Linux 上为 **Ctrl+Shift+M**），即可打开编辑框。输入评论并发布（按 ⌘↵ 可直接发布，无需使用鼠标）。选中的文字会高亮，并创建一个新讨论串。

只要有可选中的文字，就可以添加评论；**issue**、**routine** 和 **case** 文档中的操作方式相同。

### 讨论串面板

每条评论都会打开一个**讨论串面板**，你和其他人可以在其中来回回复。面板位置会适应屏幕：桌面端会停靠为**侧边面板**（文档旁的评论栏）；手机端则从底部滑出为**底部面板**，避免对话挤占文档空间。

**队友和智能体**都可以撰写评论和回复。智能体作者会在讨论串中标明，因此你能清楚区分评论来自人员还是审阅工作的智能体。

### 解决、重新打开和数量标记

每个讨论串都有状态：新建时为**未解决（open）**；处理完成后可以标记为**已解决（resolved）**。点击 **Resolve** 即可关闭讨论串；已解决讨论串会淡化显示，高亮也会变浅，但内容不会丢失——点击 **Reopen** 就可以将它恢复为 **open** 并继续讨论。

每份文档的标题栏都会显示一个小型**评论数量标记**，表示尚未解决的评论数。你可以一眼看出哪些文档仍有待处理的问题。点击该标记即可打开面板并逐项处理。

### 文档修改后仍保留高亮

即使文档内容持续变化，评论也会继续锚定在所讨论的文本上。智能体修改文档时，Paperclip 会重新定位每个高亮，因此你昨天添加的评论今天仍会指向正确段落。锚点仍稳定时，状态为 **active**。

如果底层文本变化较大，Paperclip 无法再确定位置，则会以平稳方式降级，而不会错误指向其他文字。文本已移动或发生变化的高亮会标记为 **stale**（高亮变淡，并提示需要审阅）；如果锚定的段落完全消失，讨论串会变成 **orphaned**——其对话仍保留在面板中，只是不再关联任何文本范围。无论出现哪种情况，讨论都会保留；不会因为文档更新而丢失评论。

### 分享单条评论

每条评论都有自己的可寻址链接。打开讨论串并使用 **Copy link**，即可复制直接指向该评论的深层链接。将其粘贴到任务讨论或消息中，其他人打开后会看到文档，并聚焦到相应讨论串——无需再告诉对方“滚动到第三段”。

## 快速理解模型

- **Artifacts 页面**——一个地方集中查看智能体在全公司范围内生成的所有输出。
- **类型筛选器**——将内容限定为图像、视频、文档、文本或文件。
- **堆栈**——按任务分组（或汇总到父任务）的制品，让相关输出保持在一起。
- **卡片**——可就地阅读或播放的预览，每张卡片都会链接回来源问题。
- **文件查看器**——侧滑查看器，可内嵌打开工作区文件并附带侧边文件浏览器；可从文件制品或智能体文本中的内嵌文件标记打开。
- **任务中的 Artifacts 标签**——在任务属性面板中查看该任务生成的输出；每项输出卡片会按拉取请求、提交、文档、图像、视频、链接预览、CSV 数据或文件等类型显示。
- **文档评论**——以 Google Docs 风格在 Plan 或 Artifact 文档的选定段落旁添加行内讨论串；可以保持未解决或标记为已解决，可由人员或智能体撰写，也可以通过深层链接分享。

现在你已经了解如何查找、筛选和审阅智能体生成的内容。如果想进一步了解某项制品背后的工作，可以通过链接返回来源问题并继续查看讨论。
