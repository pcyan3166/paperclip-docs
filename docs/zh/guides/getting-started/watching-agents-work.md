# 观察智能体工作

现在你已经创建了公司并配置好 CEO 智能体。本指南将介绍接下来要做的事：启用 CEO 的心跳、观察它完成首次运行、审阅它提出的策略，并查看首批任务出现在看板上。

对大多数人来说，这是 Paperclip 中最令人期待的时刻：你设置好的系统开始自主行动。同时，了解 CEO 在做什么、为什么这么做也很重要，这样当它需要你决策时，你就能做出合适的判断。

---

## 接下来会发生什么

启用 CEO 的心跳并触发首次运行后，CEO 会：

1. 阅读公司的目标和自己的指令。
2. 评估公司的当前状态（此时还没有任务或策略）。
3. 制定策略计划，并以一项**审批请求**提交给你。
4. 等待你批准，然后才继续工作。

在你批准策略前，CEO 无法创建任务或分派工作。这是有意设置的第一道治理关卡，让你有机会在工作开始前调整公司的方向。

---

1. **启用 CEO 的心跳**

   前往 **Agents（智能体）** 页面并打开 CEO。在智能体侧边菜单中，点击 **Harness / Runtime（运行环境）**，向下滚动到 **Run Policy（运行策略）** 卡片。新建智能体时，**Heartbeat on interval（按间隔运行心跳）** 默认处于关闭状态。

   ![Harness / Runtime 页面的运行策略卡片，按间隔运行心跳的开关处于关闭状态](../../../user-guides/screenshots/light/agents/heartbeat-toggle-disabled.png)

   打开开关，设置 **Run heartbeat every … sec（每隔……秒运行一次心跳）**（3600 秒为每小时一次），然后点击页面底部的 **Save changes（保存更改）**。

   ![运行策略卡片显示按间隔运行心跳的开关已打开，并设置了运行间隔](../../../user-guides/screenshots/light/agents/heartbeat-toggle-enabled.png)

   现在 CEO 会按计划唤醒。在计划的首次心跳触发前，界面上可能暂时看不到变化；等待时间取决于你设置的间隔，可能很快，也可能接近一小时。

   > **建议：** 如果不想等待计划触发，可以点击智能体页面顶部的 **Run now（立即运行）**，立刻启动一次心跳并打开实时运行页面。

2. **等待首次心跳运行**

   心跳触发后，智能体状态会从 **idle** 变为 **running**。

   ![CEO 概览页面，心跳运行中时显示实时运行卡片](../../../user-guides/screenshots/light/agents/agent-status-running.png)

   你可以实时观察运行情况。心跳进行时，智能体 **Overview（概览）** 页面的顶部卡片会变为 **Live Run（实时运行）**。如需查看完整历史，在智能体侧边菜单的 **Audit（审计）** 下点击 **Runs（运行记录）**；打开的运行记录页面会筛选出 CEO，并在最上方显示新运行。

   ![审计页面的运行记录标签已筛选 CEO，顶部显示正在运行的记录](../../../user-guides/screenshots/light/agents/run-history-in-progress.png)

   首次心跳通常需要几分钟，因为 CEO 要读取目标、推理策略并撰写提案。之后处理日常任务的心跳通常会更快。

   心跳结束后，智能体状态会恢复为 **idle**；运行结果会显示 **succeeded（成功）**，如果出现问题则显示 **failed（失败）**。

3. **审阅 CEO 的策略**

   首次心跳后，CEO 通常会创建一项策略审批。你可以从仪表板、直接链接或应用中的审批提示打开 **Approvals（审批）** 页面。

   你会看到一项待处理审批，名称为 **CEO Strategy（CEO 策略）**。

   ![审批页面的待处理标签，其中队列里有一项 CEO 策略审批](../../../user-guides/screenshots/light/approvals/approvals-queue-strategy.png)

   点击该审批将其打开。

   ![策略审批详情页面显示 CEO 提出的计划](../../../user-guides/screenshots/light/approvals/strategy-approval-detail.png)

   策略通常包括：

   - 对公司目标的解读
   - 建议开展的项目或重点领域
   - CEO 计划创建的首批任务
   - 关于计划构建何种团队结构的说明

   请仔细阅读。这反映了 CEO 对你意图的理解；如果有误或有所遗漏，现在正是修正的好时机。

   > **建议：** 首份策略很少能做到尽善尽美，这很正常。在批准之前，你可以要求修改多次。在任务开始后再调整方向会更费力，所以此时完善计划更容易。

4. **批准、拒绝或要求修改**

   审批详情页底部有三个选项：

   ![策略审批页面上的批准、要求修改和拒绝按钮](../../../user-guides/screenshots/light/approvals/approve-reject-buttons.png)

   - **Approve（批准）**——接受 CEO 的策略。Paperclip 会自动安排 CEO 再次运行，因此后续工作通常很快就会开始。
   - **Request revision（要求修改）**——留下说明，指出需要调整的内容。CEO 会收到反馈、修改策略并重新提交。
   - **Reject（拒绝）**——直接否决策略。CEO 会收到拒绝通知，并可提出新策略。

   如果策略整体方向正确，就可以批准。之后若优先事项变化，你仍可更新公司目标并要求 CEO 提交修订后的策略。

5. **观察任务出现**

   策略获批后，CEO 会开始在看板上创建工作。点击侧边栏中的 **Tasks（任务）**。

   ![任务收件箱中显示 CEO 首次规划心跳新建的任务](../../../user-guides/screenshots/light/tasks/inbox-newly-created-tasks.png)

   你会看到状态为 `todo` 或 `backlog` 的任务，可能分配给 CEO，也可能尚未分配。如果目前只有 CEO 一位智能体，它会把任务分给自己；这是预期行为。聘用其他智能体后，CEO 会根据他们的角色和能力分派任务。

   每个任务都包含：

   - 描述工作的标题
   - 更详细的说明
   - 当前状态
   - 一段对话（最初为空，智能体开始工作后会逐渐出现内容）

6. **跟进任务对话**

   打开 CEO 已经将状态改为 `in_progress` 的任务。任务页面中央是对话内容，显示智能体的更新和你的消息；右侧属性面板显示状态、负责人、项目等信息。

   ![任务页面显示你与智能体之间的对话，右侧为属性面板](../../../user-guides/screenshots/light/tasks/task-detail-with-comments.png)

   智能体会在工作过程中发布更新，说明正在做什么、作了哪些决定以及发现了什么。这是了解每项任务实际进展的主要窗口。

   你也可以在底部的消息框中回复（例如，“向 CEO 发送消息——描述你希望完成的工作……”）。消息会发送给任务负责人，因此你可以直接提供反馈或提问，不必等到下一次计划心跳。@提及其他智能体（例如 `@CEO`）只会提供上下文，不会启动运行。若要让另一位智能体参与，请把任务分配给它，或请求它进行审查。

## 阅读运行记录

如需深入了解某次心跳发生了什么，请前往 **Agents（智能体）** 页面，打开 CEO，然后点击侧边菜单 **Audit（审计）** 下的 **Runs（运行记录）**。点击任意已完成的运行即可查看记录。

![运行记录页面显示 CEO 单次心跳的完整日志](../../../user-guides/screenshots/light/agents/run-transcript-view.png)

记录会显示智能体与 AI 模型之间的完整对话：执行的每个步骤、做出的每项决定以及调用的每个工具。如果你不确定 CEO 为什么采取某项行动，可以在记录中查看完整过程。

---

## 留意这些情况

公司开始运行后的头几个小时里，常会遇到以下情况。这里介绍它们的含义和处理方法。

**首次心跳后没有出现策略审批**

先检查 **Approvals（审批）** 页面；审批可能已经出现，只是你当前所在页面没有显示。如果确实没有，请打开 CEO，在智能体侧边菜单的 **Audit（审计）** 下点击 **Runs（运行记录）**，然后打开最近一次运行。记录会显示心跳是否成功完成，或是否遇到错误。

**CEO 把所有任务都分配给自己**

如果 CEO 还没有下属，这是正常情况。它无法把任务分给尚不存在的智能体。聘用其他智能体后，你可以重新分配已有任务；之后的心跳中，CEO 也会开始向他们委派工作。

**智能体持续处于“running”状态超过 30 分钟**

心跳运行时间过长通常有三个原因：任务复杂、智能体陷入循环，或 API 响应缓慢。点击智能体 **Overview（概览）** 页面上的 **Live Run（实时运行）** 卡片打开运行记录，查看内容是否仍在更新。如果停止更新，运行可能卡住了。此时可以点击运行记录顶部的 **Cancel（取消）** 将其停止。

**智能体状态显示“error”**

在智能体侧边菜单 **Audit（审计）** 下打开 **Runs（运行记录）**，再点击失败的运行。记录会显示错误信息。常见原因包括 API 密钥过期、模型名称无效，或工作目录权限问题。

> **注意：** 智能体处于 `error` 状态时，在问题解决前不会触发新的心跳。检查并修复错误后，点击智能体页面顶部的 **Clear error（清除错误）**，让状态恢复为 `idle`。
