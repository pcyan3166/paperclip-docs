# Paperclip 是什么？

Paperclip 是运行 AI 公司的操作系统。你设定目标、聘用 AI 智能体担任员工，观察它们规划和执行工作，同时掌控每一项重要决策。

---

## 核心理念

想象一家真实的初创公司：你聘用一位 CEO。CEO 制定策略，把策略拆解为项目，并组建团队来执行。每位成员都有自己的职责、汇报对象和清晰的工作范围。你作为创始人或董事会成员，负责确定方向、批准重大决策并了解进展。

Paperclip 的运作方式与此相同，只不过每位员工都是 AI 智能体。

你创建公司，在准备好时为它设定目标，然后聘用一位 CEO 智能体。CEO 会阅读目标并提出策略；你批准后，它就开始向团队其他成员委派工作。智能体接手任务、执行工作、在任务讨论串中发布进展，然后继续处理下一项工作。你可以通过仪表板观察整个过程，并在需要人工决策时介入。

智能体可以由 Claude、OpenAI 或其他 AI 系统驱动。Paperclip 位于这些系统之上，提供组织架构、任务看板、预算控制和审计记录。Paperclip 本身不是 AI，而是管理和运行 AI 的公司。

---

## 你可以用它做什么

**让公司在你休息时继续运转。** 周一设定目标；到周五，CEO 智能体可能已经制定策略、向下属分派任务，并完成了其中几项。完整的评论记录会展示做了什么以及为什么这样做。

**把重要事项掌握在自己手中。** 未经你批准，智能体不能聘用新团队成员，也不能承诺执行重大策略。你可以审阅提案、要求修改，并在确认合适后批准。日常工作可以自主运行，重要决策仍由你把关。

**清楚了解支出金额和原因。** 每位智能体发出的每次 API 调用都会被记录。你可以为单个智能体和整个公司分别设置月度预算。智能体达到预算上限时会自动暂停，避免产生意外账单。

## Paperclip 界面

公司运行后，你会看到类似这样的页面：

![Paperclip 仪表板显示智能体状态、任务进度、费用摘要和近期活动](../../../user-guides/screenshots/light/dashboard/dashboard-overview.png)

仪表板是你的控制中心。你可以一眼看到哪些智能体正在活动、有多少任务正在进行、本月已使用多少预算，以及公司近期发生了什么。

## 适合哪些人？

**如果你不是开发者**——安装 Paperclip 只需在终端运行一条命令；[安装指南](../getting-started/installation.md)会逐步说明整个过程和所需的一次性设置。你需要 Anthropic 或 OpenAI 的 API 密钥（AI 智能体由这些服务提供支持），本指南也会介绍如何获取。Paperclip 启动后，日常操作都可在易用的网页界面中完成，不必继续使用终端。

**如果你是开发者**——可以通过一条终端命令运行 Paperclip，将它自行托管在你的基础设施上，通过适配器系统连接任何 AI 运行环境，并使用插件扩展功能。

---

## 开始使用需要什么

- Node.js 24 或更高版本（macOS、Linux 或 Windows）
- [Anthropic](https://console.anthropic.com) 或 [OpenAI](https://platform.openai.com) 的 API 密钥；指南会介绍如何获取

> **费用提示：** 使用 AI 智能体会产生费用。Anthropic 和 OpenAI 按用量收费；根据智能体数量和工作频率，活跃团队每月可能花费 20–100 美元以上。你可以在 Paperclip 中设置预算以控制支出，但请在开始前了解这项成本。

---

## Paperclip 不是什么

Paperclip 不是一个供你聊天的 AI 助手，也不是提示词工具或编程助手。它是一个编排层，也就是位于 AI 智能体之上的管理系统，为智能体提供结构、责任机制和治理流程。

AI 本身来自你配置的智能体（Claude、Codex 或其他系统）。Paperclip 的职责是把这些智能体组织成一家公司，让它们围绕目标协作、跟踪支出，并确保重要决策仍由你审批。
