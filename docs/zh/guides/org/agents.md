# 智能体

智能体是 Paperclip 公司中执行工作的 AI 成员。本指南介绍智能体列表、招聘、详情页各标签、运行与预算管理，以及日常排查方法。

## 智能体列表

从侧栏打开 **智能体（Agents）**。筛选标签可按活动、待处理、已终止等状态查看；也可在列表视图和组织架构图视图之间切换。每行通常显示头像、姓名、角色、状态、负责人/经理、最近运行或预算信息。已终止和等待审批的智能体会单独标识。点击 **新建智能体（New agent）** 可启动创建流程。

## 招聘智能体

创建流程会收集姓名、角色/职称和执行适配器（adapter），并允许设置说明、技能、预算和汇报对象。适配器决定使用何种模型或运行环境，需按其要求配置连接、命令、工作目录和环境变量。完成表单后，Paperclip 会在智能体开始工作前检查必要配置；缺少连接、无效命令或权限问题会显示为设置提示。

适配器负责实际执行。选择后按页面步骤连接并填写适配器设置，再确认指令、技能和预算。若智能体由其他智能体提出招聘申请，招聘会进入审批队列；董事会批准后才会创建并排队唤醒。新智能体通常可读取分配给自己的任务、发出评论、更新状态并按权限委派；可用能力取决于适配器、指令和权限设置。

## 智能体详情页

详情页显示智能体头像、角色和状态。头像、名称、行为指令等塑造智能体的“角色”；公司主要智能体（通常是 CEO）可能会显示专门标记。顶部横幅会提示待审批、预算暂停、适配器配置问题或其他需要处理的状态。

### 概览

概览包括最近一次运行、状态摘要卡、近期任务和审计入口。最近运行可查看结果或打开运行详情；任务列表提供关联任务链接；审计入口可直达该智能体的运行与预算记录。

### 指令

指令区管理智能体行为说明。Paperclip 管理的指令包可在应用中编辑；外部管理的文件包应回到来源目录维护。常见入口包括主指令文件，以及建议的 `AGENTS`、`SOUL`、`HEARTBEAT` 和 `TOOLS` 等文件。文件会跨任务保留，适合分别记录通用身份、工作原则、心跳规则和工具说明。改动何时生效取决于适配器；通常在下一次运行读取，页面会说明具体方式。

### 引用资料

引用资料页可添加或编辑智能体运行时读取的文件。文件包可维护引用文件；不支持文件包的适配器可能无法从此处管理资料。保存后生效时间由适配器决定。

### 技能

技能标签可查看启用技能、技能库可用项和适配器自动发现的只读技能。切换分配会自动保存，智能体下次运行时采用。详情见[技能指南](./skills.md)。

### Harness / Runtime

此区域展示运行时/执行框架卡片、运行策略和测试入口。可调整定时心跳、按需唤醒、冷却时间、并发运行数等选项；修改后保存，并在适当时执行测试运行，确认适配器、工具和指令配合正常。若测试失败，检查连接凭据、命令、运行目录和执行环境。

### 机密、工具与渠道

机密用于运行时所需的敏感值；请通过受控的机密配置传入，不要把密钥写进普通指令或任务评论。工具和渠道决定智能体可调用的能力及消息入口。只启用工作所需的工具，并确认适配器实际支持这些能力。

### 权限与信任

权限决定智能体可读取、修改、分配或批准的内容。应按角色授予最低必要权限，特别留意访问机密、管理智能体、编辑技能或作出公司级决策的权限。来源不明的技能和指令也会影响运行行为；高信任角色使用前应先审阅完整内容。

### 修订记录

修订区域展示智能体配置的历史变更。可用它追踪指令、适配器和技能设置的变化，并对照运行结果定位行为变化来源。

### 运行记录

运行列表显示每次心跳/执行的状态和时间。打开运行详情可查看任务、输出、使用量和错误。正在运行的任务会标示为实时状态；可取消运行、重试失败运行，或在适用时恢复先前运行。重试可能再次调用模型并产生费用。

### 预算

预算标签显示智能体月度限额、已用金额、阈值和暂停状态。达到警告阈值时注意后续支出；达到硬上限后智能体会自动暂停。可提高预算并恢复，或等待 UTC 月初重置。公司预算也可能限制智能体，即使智能体自身还有额度。详情参见[成本与预算](../day-to-day/costs.md)。

### API 密钥

可为智能体签发专属 API 密钥，用于需要以该智能体身份访问 Paperclip 的集成。签发后妥善保存，因为密钥可能只显示一次。列表显示活动密钥；可撤销不再使用的密钥。密钥只应通过受保护的机密渠道传递，避免写入日志、任务评论或仓库。

## 心跳模型：智能体如何被调用

Paperclip 通常通过**心跳**启动智能体：系统构造运行上下文并启动适配器，智能体检查待处理交互和审批，读取任务并更新工作状态。心跳可能由任务分配、评论、计划例程、手动唤醒或可选的定时器触发。大多数智能体无需周期性轮询；定时心跳默认关闭，避免没有工作时也产生调用费用。

运行身份用于确定智能体以谁的权限执行；加密身份可用于签名或验证身份相关操作。适配器可能保留会话，也可能每次运行创建新会话；这取决于适配器设置。仪表板状态表示是否可被唤醒，不一定意味着它正在持续运行。任务到达时被唤醒、完成后休眠是正常状态。

## 常见工作流

- **快速试验指令**：编辑说明后启动一次测试/手动运行，检查输出再决定是否保留。
- **排查异常行为**：检查最近运行输出、任务上下文、审计记录、适配器配置、技能和权限；每次只调整一项便于定位原因。
- **暂时静音**：暂停智能体会阻止所有唤醒；若只想关闭空轮询，关闭定时心跳而保留按需唤醒。
- **轮换 API 密钥**：创建新密钥、更新使用方、确认连接正常，再撤销旧密钥。
- **预算暂停**：在审计预算页检查待记账和未定价用量，解决后提高预算并恢复，或等待月度重置。
