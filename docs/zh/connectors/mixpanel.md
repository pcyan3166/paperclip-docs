# Mixpanel

智能体可以查询您的 Mixpanel 产品分析数据——运行报告、检查事件量以及回答有关产品使用情况的问题。

> **警告：** Mixpanel 的托管服务器处于测试版阶段。请预期可用工具及其行为可能会发生变化，并在提供商更新后重新阅读连接的操作列表，而不是假设上个月的界面保持不变。

## 连接前准备

- 一个具有访问权限的 Mixpanel 账户，以便智能体能够查询您指定的项目。
- 如果您的组织使用 Mixpanel 的欧盟或其他区域驻留服务，请使用属于该区域的账户登录。Paperclip 在此连接中没有区域选择器，因此区域取决于您授权的账户；如果选择错误，通常表现为连接授权成功但随后找不到数据。

## 连接 Mixpanel

1. 打开 **连接器** 并选择 **Mixpanel**。
2. 阅读主按钮上方的访问权限说明行。它说明了连接以谁的身份登录以及哪些智能体可以使用它。若要选择其他身份、缩小智能体范围或使用其他登录方法，请选择 **更改**。
3. 选择 **继续前往 Mixpanel** 并完成浏览器登录，在提示时选择项目。

Paperclip 会自动注册其客户端，因此无需在开发者控制台中进行任何配置。

## 选择访问权限

项目访问范围取决于授权 Mixpanel 账户的权限，并受 Mixpanel 自身项目权限的限制。除了 Mixpanel 在登录期间询问的内容外，Paperclip 中没有项目选择器。

此连接器主要用于读取。需要管理的重点不是破坏性操作，而是成本和数据量：

> **注意：** 针对长日期范围和高频事件的查询速度较慢，并可能触及 Mixpanel 的查询限制。智能体提出的开放式问题可能会生成比人类用户大得多的查询。请为智能体提供有界的问题——例如指定的报告或特定的时间窗口——而不是“分析我们的使用情况”。

如果连接暴露了任何写入功能——保存报告、更改项目配置——请将其视为写入操作，并将其置于审批流程之后。参见 [设置操作权限](action-permissions.md)。

事件数据通常包含用户标识符和属性。查询 Mixpanel 的智能体可能会将这些信息暴露到任务记录中，因此建议优先选择 **仅我选择的智能体**。

## 尝试使用

请求一个您已知答案的小型数据：

```txt
How many times did the "signup_completed" event fire in Mixpanel in the last 7 days?
```

将其与 Mixpanel 界面中的相同数据进行比较。在短时间窗口内查询单个事件成本低且无歧义，因此是良好的首次检查。

> **注意：** 这是一个示例任务，而非记录在案的测试结果。请替换为您自己项目中的事件名称。

## 故障排除与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 授权成功但项目看起来是空的 | 选择了错误的项目，或账户位于不同的数据区域 | 重新连接并选择预期的项目 |
| 查询立即失败并显示授权错误 | 凭据或账户的项目权限 | 在 Mixpanel 中检查账户的访问权限 |
| 查询运行一段时间后失败 | 查询限制或速率限制，而非认证问题 | 缩小日期范围或事件集，然后重试 |
| 数字与 Mixpanel 界面不一致 | 与界面报告相比，日期范围、时区或过滤器不同 | 询问智能体使用了哪个时间窗口和过滤器 |
| 某个工具消失或发生变化 | 托管服务器处于测试版阶段 | 使用 **刷新操作** 并重新检查列表 |
| **需要关注** | 授权已过期或被撤销 | 选择 **重新连接** |

限制：由于提供商界面处于测试版阶段，工具列表可能会变动。查询成本和速率限制由 Mixpanel 决定。

> **注意：** Paperclip 在此连接器中没有项目选择器，因此可访问的项目取决于授权的 Mixpanel 账户及其自身的项目权限。提供商的服务器是否进一步将会话限制为单个项目属于 Mixpanel 的行为，我们尚未对此进行验证——如果智能体必须被限制在单个项目中，请使用仅具有该项目访问权限的账户进行授权，而不是依赖我们无法证实的限制。
