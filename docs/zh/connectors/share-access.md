# 将连接器共享给人员和智能体

对于带有凭据的应用工具连接，存在两个独立的受众群体：凭据所属的人员，以及允许通过该凭据进行调用的智能体。扩大其中一个受众范围并不会自动扩大另一个。

## 检查设置默认值

新的工具连接通常默认包含您组织内的所有人员和所有智能体。设置界面会在主按钮上方显示已解析的身份和智能体受众；选择 **Change**（更改）可在同一屏幕上缩小这些范围。

仅限个人登录的方法使用您的身份。从任务中为智能体请求的连接通常默认包含您本人和该智能体；AgentMail 则使用公司范围内的人员访问权限和所选收件箱的所有者。重用已保存的连接会保留其现有的访问权限。

## 选择人员受众

打开连接器并找到其身份卡片。

**对于个人连接**（**Just me**，仅我），无需选择。该凭据属于您，且*“只有您可以使用此连接。”*

**对于组织身份**，选择 **Who can use this identity**（谁可以使用此身份）：

| 选项 | 效果 |
| --- | --- |
| **Any human in the company**（公司内任何人员） | *“您公司内的任何人都可以使用此连接。”* |
| **Humans I pick**（我选择的人员） | *“仅您公司内选定的人员。”* 选择 **Choose people**（选择人员）并指定姓名。 |

保存。更改将在下一次运行时生效；无需重新连接。

创建或更改组织身份需要连接管理器权限。如果没有该权限，Paperclip 会在服务器端拒绝更改，而不是隐藏控件并抱有侥幸心理。

**对于专用智能体身份**，人员受众不是一个列表——该身份属于单个智能体。卡片显示*“专用于一个智能体”*并链接到该智能体。参见 [为人员和智能体使用独立账户](separate-accounts.md)。

## 选择允许使用它的智能体

对于应用工具连接，打开 **Permissions**（权限）选项卡并找到 **Which agents can use this connection**（哪些智能体可以使用此连接）。模型凭据和聊天频道使用其自身的分配控件；参见其提供商指南。

| 选项 | 效果 |
| --- | --- |
| **Any agent**（任何智能体） | *“在您公司范围内可用。”* |
| **Just agents I pick**（仅我选择的智能体） | *“仅对选定智能体可用。”* 选择 **Choose agents**（选择智能体）并指定名称。 |

如果控件被禁用并显示*“当此连接为所有智能体安装时不可用”*，则表示该连接具有公司范围的安装，该安装优先于按智能体划分的列表。请先更改安装设置。

您也可以保存 **Just agents I pick**（仅我选择的智能体）而不选择任何智能体，如果您希望先建立连接，稍后再授予访问权限。对于提供商托管的连接器，该选择将在提供商的登录过程中保持有效：当您从授权返回时，连接仍然没有关联任何智能体，而不是默认对所有智能体开放。

在设置过程中检查已声明的受众，并在需要时进行更改。对连接的访问权限并不决定智能体可以执行的操作；操作列表仍然控制每次调用。参见 [设置操作权限](action-permissions.md)。

## 为什么这是两个列表

人员受众决定消耗谁的凭据以及谁的同意支持该调用。智能体访问权限决定您组织架构图中的哪些部分能够触及该服务。

在实践中，这两者经常分离。例如，财务连接器可能作为身份共享给整个公司，但限制为单个记账智能体使用。个人 Gmail 连接是某一个人的邮箱，但您可能仍希望您的三个智能体能够代表您搜索该邮箱。

## 检查您所做的更改

连接器列表显示每个连接的当前状态。对于身份在不同安装中混合的连接，卡片显示*“混合访问；范围因安装而异”*，而不是将其简化为单一声明。

从 Composio、Arcade 或 Executor 导入的账户显示在其应用卡片下。其访问权限在已保存的提供商网关上管理，并适用于该网关下的所有应用。刷新该账户清单永远不会扩大人员或智能体受众。
