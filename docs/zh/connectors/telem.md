# Telem.AI

智能体可以通过 Telem.AI 搜索网络并阅读页面——当任务需要获取公司外部的最新信息时，这非常有用。Telem.AI 将每次搜索请求发送到多个搜索提供商，而您只需使用一个 API 密钥，因此无需为每个提供商单独注册。

> **注意：** Telem.AI 出现在每个实例的目录中；无需启用实验性设置。

## 连接前准备

- 一个 Telem API 密钥。请在 Telem 控制台 [app.telem.ai](https://app.telem.ai) 中创建。密钥以 `tlm_` 开头。

没有浏览器登录，也没有免费个人资料；密钥是唯一的访问方式。使用量将计入拥有该密钥的 Telem 账户。

## 连接 Telem.AI

1. 打开 **连接器** 并选择 **Telem.AI**。
2. 阅读主按钮上方的访问权限说明行。它显示了连接所属者以及哪些智能体可以使用它。选择 **更改** 以缩小智能体范围或访问下方的可选设置。
3. 将密钥粘贴到 **您的 Telem.AI 密钥** 字段中，然后选择 **连接**。

Paperclip 将密钥作为机密存储，并在每次调用时发送给 Telem.AI；智能体永远不会看到该密钥。

### 可选设置

您可以将所有这些项留空。无论您选择什么，都将应用于使用此连接的每个智能体。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| **自动路由** | 关闭，准确性 | **准确性** 允许 Telem 为每个查询选择搜索提供商。关闭或未选择则保持自动路由关闭。 |
| **层级** | 极简，默认，扩展，最大 | Telem 为每个查询执行的搜索工作量。未选择时使用 **默认**。 |
| **包含的提供商** | 逗号分隔的提供商名称 | Telem 仅搜索这些提供商。留空则允许所有提供商。 |
| **排除的提供商** | 逗号分隔的提供商名称 | Telem 跳过这些提供商。 |

一旦从列表中选择了某个值，就无法将其恢复为空。若要再次关闭自动路由，请选择 **关闭**。

## 选择访问权限

此连接器从公共网络读取数据；它不会访问您自己的数据。这使其成为风险较低的共享连接器之一，其操作默认状态为 **允许**。

仍有三件事值得决定：

- **谁付费。** 每个拥有访问权限的智能体都使用同一个 Telem 账户。更高的层级意味着每个查询的搜索工作量更大。如果某个繁忙的智能体导致使用量激增，请为其提供使用单独密钥的独立连接。
- **Telem 看到什么。** Paperclip 会告知 Telem 每次搜索来自哪个公司、项目、任务、智能体和运行，以便您可以在 Telem 端追踪使用情况。搜索词本身会发送给搜索提供商，因此请避免在查询中包含私密细节。
- **智能体如何处理结果。** 搜索结果属于外部内容。智能体应将其视为需要核查的信息，而非需要遵循的指令。有关在其他连接器中将后续操作保持在 **先询问** 状态，请参阅 [设置操作权限](action-permissions.md)。

## 试用

```txt
Search the web with Telem.AI for the latest release notes of a tool we use, and summarise the top three results with their links.
```

打开智能体返回的链接。如果搜索结果带有可核查的来源，就能确认连接状态和智能体权限。

> **注意：** 这是示例任务，而非记录在案的测试结果。

## 故障排查与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 密钥被拒绝 | 密钥已被撤销或复制不完整 | 在 app.telem.ai 创建新密钥并重新连接 |
| 提供商名称被拒绝 | 列表中包含空格或其他字符 | 仅使用逗号分隔的名称，且只包含字母、数字、`.`、`_` 或 `-` |
| 结果从未来自预期的提供商 | 该提供商被排除，或不在 **包含的提供商** 中 | 在 **更改** 下检查这两个列表 |
| 使用量高于预期 | **层级** 较高，或许多智能体共享一个密钥 | 降低层级或拆分连接 |
| **需要关注** | 密钥已被撤销 | 使用有效密钥选择 **重新连接** |

限制：每个连接对应一个 Telem 账户。可用的操作取决于 Telem.AI 托管服务器所暴露的内容。
