# 连接自定义 MCP 服务器

目录涵盖了 Paperclip 已审核的提供商。对于其他情况——您自行运行的服务器、未列出的提供商，或提供商为您生成的 URL——**连接器**页面上有三个入口。

## 连接您自己的 MCP 服务器

*“输入自定义或自托管 MCP 服务器的 URL。”*

选择 **连接您自己的 MCP 服务器**，粘贴完整的 `http` 或 `https` 地址，让 Paperclip 自动确定服务器所需的内容：*“Paperclip 会询问服务器需要什么，并引导您完成设置。请从这里开始。”*

接下来的步骤取决于服务器：

- **它支持 OAuth。** Paperclip 注册一个客户端并引导您通过浏览器登录。如果授权服务器既不支持客户端 ID 元数据文档，也不支持动态注册，Paperclip 将停止操作，并要求您提供自行注册的客户端，而不是丢弃草稿连接。
- **它需要密钥。** Paperclip 会要求提供密钥，并说明其用途：*“Paperclip 将您的密钥作为 Authorization 标头发送。”* 对于期望其他内容的服务器，可以使用自定义标头。
- **它不需要任何凭据。** Paperclip 会明确说明：*“该服务器对拥有地址的任何人都开放。”* 请将此地址视为凭据。

### 在访问令牌过期后保持登录状态

许多 OAuth 服务器颁发短期有效的访问令牌。为了在访问令牌过期后保持自定义服务器连接，当服务器的授权服务器将其列为受支持且未排除刷新令牌时，Paperclip 还会要求提供 `offline_access`，即使 MCP 服务器本身仅提及工具范围。当提供商颁发刷新令牌时，Paperclip 会在后台续期访问权限，智能体无需再次登录即可继续工作。

提供商仍决定颁发刷新令牌。如果提供商不颁发刷新令牌，则每次访问令牌过期时，连接都需要重新登录。在此更改之前创建的旧自定义连接，将在您下次选择 **重新连接** 时获得刷新支持。

目录外未审核的服务器将被标记为 **未经验证的服务器**。该标签仅表示审核状态，不代表连接是否有效。

## 粘贴配置

*“粘贴现有的配置片段并连接。”*

如果您已有可用的 MCP 客户端配置——来自其他工具、提供商的快速入门指南或同事——**粘贴配置** 功能将从中提取服务器 URL 和凭据格式，而无需您重新输入。Paperclip 在保存前会验证结果。

## 粘贴提供商生成的 URL

某些提供商会提供一个已嵌入令牌的单一 URL。Zapier 是目录中此类形状的条目：*“粘贴 Zapier 提供的完整 MCP URL，包括其令牌。”*

URL 是机密信息。持有该 URL 的人即拥有访问权限。Paperclip 将其作为机密信息存储，且连接的权限操作与其他连接器的应用方式相同。

Arcade、Composio 和 Executor 的工作方式类似——您粘贴其服务提供的 MCP URL，并在要求时进行登录——但每个服务都有各自的目录条目，包含针对该提供商的设置步骤。如果您想要的应用程序可以通过其中之一访问，请从 [通过 MCP 聚合器连接应用](mcp-aggregators.md) 开始，而不是使用自定义服务器。

## 背后的两个通用定义

Paperclip 有两个目录条目，旨在支持通用路径，而非供浏览使用：

| 定义 | Slug | 形状 |
| --- | --- | --- |
| **OAuth 应用** | `oauth-generic` | *“使用您自己的 OAuth 客户端连接提供商。”* 您提供客户端 ID 和客户端密钥；当提供商支持时，使用动态注册。 |
| **API 密钥应用** | `api-key-generic` | *“使用来自提供商的密钥连接 API。”* 您提供密钥，Paperclip 在每次调用时呈现该密钥。 |

这两者均不出现在 **连接器** 列表中。它们通过上述通用入口访问。

## 治理完全相同

自定义服务器并非二等公民。相同的四个关卡适用：连接、身份、智能体访问和逐操作权限。操作列表从您指向的服务器读取，分类为读取、写入或破坏性操作，并将每个条目设置为 **允许**、**先询问** 或 **关闭**。

由于服务器未经审核，建议保持以下两种习惯：

- 初始将所有写入操作设置为 **关闭**，并有意提升权限。当服务器未发布注释时，基于名称的分类是后备方案，而不熟悉的命名方案可能导致分类不足。
- 在更改服务器后重新运行 **刷新操作**，然后审查列表。在粘贴 URL 的连接中，新发现的操作将在现有策略下立即生效——它不会被扣留等待批准——因此刷新可能会扩大智能体可以调用的范围。

## 添加保存的指导

自定义连接可以通过连接 API 存储可选的 `agentInstructions`。该指导仅包含在可以使用其至少一个工具的授权运行中，且从不授予额外访问权限。

当前的 **智能体指令** 编辑器仅在连接器声明模板时出现；它不会在每个自定义服务器上显示。Paperclip 不会自动将服务器的初始化文本采用为受信任的指令。有关该设置及其行为，请参阅 [保存的连接指令](connection-instructions.md)。

## 与适配器 MCP 服务器不同

将 MCP 服务器附加到智能体的 *运行时*——通过适配器自身的配置——是一种具有不同治理机制的不同机制。Paperclip 的操作权限和审核队列不位于其前面。有关该路径，请参阅 [为智能体添加 MCP 服务器](../how-to/add-mcp-server-to-agent.md)，并有意选择而非偶然选择。
