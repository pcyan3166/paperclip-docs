# Stripe

智能体可以通过 Stripe 的托管服务器与您的 Stripe 账户进行交互——查找客户、付款、订阅和产品，并在获得批准后对其执行操作。

> **警告：** 此连接器访问真实的财务数据，其写入操作是真实的财务操作。Stripe 的托管服务器处于公开预览阶段。请从测试模式开始，并对任何涉及资金流动的操作要求审批。

不要根据名称假设特定功能。智能体能够执行的操作完全取决于 Stripe 服务器向您的凭据暴露的内容以及您已授权的内容——退款、付款和创建支付并非自动可用，也并非自动缺失。请阅读连接的操作列表，而不是在任一方向上进行猜测。

## 连接前准备

- 一个 Stripe 账户。首次连接请使用**测试模式**账户或测试密钥。
- 如果使用密钥，请创建一个仅包含智能体所需权限的**受限密钥**，而不是完整的秘密密钥。

受限密钥是此连接器的主要控制手段。Stripe 允许您授予对特定资源类型的只读访问权限，这比 Paperclip 事后能应用的任何控制都更为精确。

> **警告：** Paperclip 的密钥字段显示占位符 `sk_...`，这是一个携带您账户完整 API 访问权限的标准秘密密钥。**受限密钥**——其 ID 以 `rk_` 开头——可以在同一字段中使用，这是您应该使用的类型。请勿将该占位符解读为推荐做法。

> **注意：** 密钥是测试模式还是实时模式，在您于 Stripe 中创建密钥时即已决定，这决定了智能体是否接触真实资金。Paperclip 中没有任何内容显示或更改此设置，因此请清晰标记您的连接，并在将任何内容连接到生产环境之前，在 Stripe 中检查密钥的模式。

## 连接 Stripe

1. 打开**连接器**并选择**Stripe**。
2. 阅读主按钮上方的访问行。它说明了连接以谁的身份登录以及哪些智能体可以使用它。若要选择不同身份、缩小智能体范围或使用其他登录方法，请选择**更改**。
3. 检查您将如何认证。设置从推荐方法开始；若要使用另一种方法，请选择**更改**：
   - **使用 Stripe 登录** — 浏览器登录。
   - **使用 API 密钥** — 粘贴在 Stripe 仪表板的 [API 密钥](https://dashboard.stripe.com/apikeys) 下创建的 Stripe 密钥。
4. 完成设置。

> **危险：** Stripe 秘密密钥授予完整的账户访问权限，包括资金流动。除非有特定原因，否则仅粘贴受限密钥，切勿将实时秘密密钥粘贴到未经测试的设置中。

## 选择访问权限

分为两层，且 Stripe 侧的控制更强：

| 层级 | 控制位置 | 精度 |
| --- | --- | --- |
| 凭据可执行的 API 操作 | Stripe，在受限密钥上 | 按资源，读或写 |
| 智能体是否可调用暴露的操作 | Paperclip，在**权限**选项卡上 | 按操作，需审批 |

使用受限密钥来移除功能，并使用 Paperclip 的设置来要求对剩余功能进行审查。

测试模式与实时模式完全由您连接的凭据决定。测试模式密钥仅能访问测试数据。Paperclip 中没有开关可以将实时连接切换为测试模式，因此如果您需要两者，请创建两个连接并清晰命名。

> **警告：** Stripe 自身的指导原则是，财务和破坏性操作在执行前需要明确批准。请将所有写入操作保持在**先询问**或**关闭**状态。此处的**允许**写入意味着智能体可以在人员查看之前更改财务记录。

参见 [设置操作权限](action-permissions.md)。

## 试用

对测试数据执行读取操作：

```txt
Look up the most recent Stripe customer and tell me their email and when they were created. Do not create, refund, or change anything.
```

与相同模式下的 Stripe 仪表板进行比较。切勿使用付款、退款或付款来验证此连接器——即使金额很小，这些也是真实操作。

> **注意：** 这是示例任务，而非记录的测试结果。请先在测试模式连接上运行。

## 故障排查与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 智能体看不到数据 | 凭据处于测试模式而您正在与实时模式比较，或反之 | 检查所连接凭据属于哪种模式 |
| 操作被 Stripe 拒绝 | 受限密钥不包含该权限 | 在 Stripe 中有意扩大密钥权限，或保持该功能关闭 |
| 列表中缺少某操作 | Stripe 服务器未向此凭据暴露该操作 | 使用**刷新操作**；否则该操作不可用 |
| 财务操作未经审查即执行 | 设置为**允许** | 将写入操作设置为**先询问**或**关闭** |
| 行为发生变化但 Paperclip 未更改 | 托管服务器处于公开预览阶段并在演进中 | 在提供商更改后重新阅读操作列表 |
| **需要关注** | 密钥已轮换或登录已过期 | 选择**重新连接** |

限制：每个连接仅限一个 Stripe 账户和一种模式。Paperclip 无法撤销财务操作。公开预览意味着界面可能会发生变化。
