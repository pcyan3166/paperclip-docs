# PostHog

智能体可以在 PostHog 中查询产品分析数据、调查错误，并检查功能标志和实验。

PostHog 拥有一个庞大且快速变化的工具目录，这影响了 Paperclip 的处理方式：如果 PostHog 未将某个工具标注为只读，该工具将被分类为**写入**，且 `exec` 始终被视为**破坏性**操作。这种保守的分类是有意为之的，下文将对此进行解释。

## 连接前准备

- 一个能够访问您希望智能体使用的 PostHog 项目的账户。
- 可选：您打算固定的项目 ID。您可以在 PostHog 的项目设置中找到它。

## 连接 PostHog

1. 打开**连接器**并选择**PostHog**。
2. 阅读主按钮上方的访问说明行。它说明了连接以谁的身份登录以及哪些智能体可以使用它。若要选择其他身份、缩小智能体范围或使用其他登录方法，请选择**更改**。
3. 检查您将如何认证。设置将从推荐的方法开始；若要使用另一种方法，请选择**更改**：
   - **使用 PostHog 登录** — 浏览器登录，这是最快的路径。
   - **使用个人 API 密钥** — 粘贴 PostHog 个人 API 密钥。
4. 可选设置下方的高级控件，然后完成设置。

默认设置无需其他操作即可正常工作。

## 缩小连接范围

PostHog 在设置时提供了比大多数连接器更多的范围控制选项，这些选项值得使用：

| 控件 | 功能说明 |
| --- | --- |
| **固定到项目 ID** | 将连接范围限定为单个项目 |
| **只读模式** | 向 PostHog 请求只读会话 |
| **功能组** | 留空表示所有功能组，或列出您想要包含的功能组 |
| **单个工具** | 留空表示所有工具，或指定确切要暴露的工具名称 |
| **工具响应模式** | 工具响应携带多少细节 |

> **注意：** 这些是 **Paperclip 发送给 PostHog 的请求**，而非 Paperclip 强制执行的边界。固定的项目作为请求头传输，其余作为查询参数传输，因此由 PostHog 来遵守这些设置。您看到的效果是工具列表和项目范围变窄，这值得配置——但如果您需要一个不依赖于提供方的边界，请使用一个根本无法访问其他项目的账户或密钥，并设置操作权限。

固定到项目仍然是此处最有用的设置。如果没有固定，连接的可达范围将是授权账户能看到的所有项目。

对于仅用于分析的智能体，请固定项目并开启只读模式。

## 选择访问权限

项目可达范围属于 PostHog 账户，通过您设置的固定项进行缩小，并由 PostHog 遵守。在此基础上，Paperclip 的操作设置照常应用——这些设置在 Paperclip 端强制执行。

对于此提供方，风险分类故意采取保守策略：

- 如果 PostHog 未明确将某个工具标注为只读，该工具将被分类为**写入**，而非读取。当目录经常变化时，对不熟悉的工具静默假设为“读取”是应当避免的失败模式。
- `exec` 工具始终被分类为**破坏性**，无论其外观如何。
- 由于分类决定了设置向导投射到策略中的默认值，PostHog 连接的初始状态比那些提供方仔细标注其工具的连接器更严格。

实际效果是，您会发现比其他连接器有更多的工具默认需要审查。这是预期行为，而非误分类。

> **警告：** 分类不是审查队列。在使用您自己的 API 密钥建立的 PostHog 连接中，当 PostHog 稍后添加新工具时，该工具在您**刷新操作**时会变为**活动**状态——它受现有策略的管辖，而不是被扣留等待您的批准。请在刷新后检查列表。[设置操作权限](action-permissions.md) 解释了哪些连接会扣留新操作。

## 试用

```txt
In PostHog, how many pageviews did we get in the last 7 days? Do not create or change anything.
```

将其与 PostHog 界面中的相同数据进行比较。小型、有界的查询是合适的初步检查——在仅验证连接是否工作时，避免请求大型无界导出。

## 故障排查与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 智能体查询了错误的项目 | 连接未固定 | 设置**固定到项目 ID**，如有必要请重新连接 |
| 许多工具显示需要批准 | 预期行为——未标注的 PostHog 工具被分类为写入 | 审查并将您想要允许的工具设置为**允许** |
| 看似读取的工具被分类为写入 | PostHog 未将其标注为只读 | 如果您已检查其功能，请有意将其设置为**允许** |
| `exec` 不能随意允许 | 它始终被分类为破坏性 | 除非有具体且经过审查的理由，否则保持**关闭** |
| 缺少写入工具 | **只读模式**已开启 | 关闭它，或创建一个不包含此模式的连接 |
| 新 PostHog 工具未出现在列表中 | 列表已过期；PostHog 更改了其目录 | 使用**刷新操作**，然后检查新工具的设置——在自凭据连接中，它将在现有策略下以活动状态到达，因此请确认其位置是否符合您的预期 |
| 查询超时或被限流 | PostHog 自身的查询限制，而非 Paperclip 的限制 | 缩小时间范围或查询范围 |

限制：每个连接对应一个 PostHog 账户。固定操作限制项目范围，但如果取消固定，则不限制账户原本可达的范围。查询成本和速率限制由 PostHog 负责。
