# OpenAI

OpenAI 连接为智能体提供运行 OpenAI 模型所需的凭据。这是模型访问权限，而非一组工具——没有需要许可的操作。

有两种身份验证方式：通过 Codex CLI 进行订阅登录，或使用 OpenAI API 密钥。

## 连接前准备

- 要么拥有支持 Codex CLI 登录的套餐，要么拥有来自 [OpenAI 仪表板](https://platform.openai.com/api-keys) 的 OpenAI API 密钥。
- 一个在 Codex 上运行的智能体：使用 **Codex** 适配器，或使用 **Codex** 提供方的 **Paperclip Runner**。标准的 OpenAI 连接与 Claude 或 OpenCode 框架不兼容。如需兼容的 Responses 端点，请参阅 [自定义模型提供方](custom-model-providers.md)。
- 仅限订阅登录：需要一个登录环境——即 Paperclip 服务器主机，或支持交互式登录的沙箱环境。请参阅 [使用订阅](#with-a-subscription)。

## 选择登录方式

| 方式 | 适用场景 | 计费 |
| --- | --- | --- |
| **订阅** | 希望智能体运行消耗包含 Codex 的套餐额度 | 适用您的 OpenAI 套餐条款和限制 |
| **API 密钥** | 希望按量计费、独立账单或无需交互式登录 | OpenAI 按令牌向密钥所属组织计费 |

> **警告：** 这两者不可互换。订阅路径用于身份验证 Codex CLI，因此涵盖 Codex 运行时智能体运行——它不是用于其他集成的通用 OpenAI API 凭据。如果需要任意 OpenAI API 访问权限，请使用 API 密钥。

请与 OpenAI 确认当前的套餐权益和限制，不要想当然；这些限制独立于 Paperclip 发生变化。

## 连接 OpenAI

1. 打开 **连接器** 并选择 **OpenAI**。
2. 选择登录方式。

设置是一个单屏界面，没有单独的访问步骤。一旦账户保存，您可以从已保存的连接中更改哪些人员和智能体可以使用它。

### 使用 API 密钥

粘贴密钥。Paperclip 将其存储为机密信息，之后不可读取。

### 使用订阅

登录在 **登录环境** 中运行，有两种类型。您的实例提供哪些环境是配置问题，而非每个连接的选择：

| 登录环境 | 所需条件 | 登录方式 |
| --- | --- | --- |
| **Paperclip 服务器主机** | 该主机上的 `codex` CLI 和 Python 3（Docker 镜像包含两者），以及一个活动的本地环境 | Paperclip 在主机上为您运行登录，并在浏览器中显示 **登录 OpenAI** 链接和一次性代码。您不需要终端 |
| **沙箱环境** | 由管理员配置的支持交互式登录的沙箱提供方 | 登录发生在 Paperclip 提供的环境中；服务器主机上不需要终端 |

当两者都可用时，Paperclip 会显示 **登录环境** 选择器。用于登录的环境可能与智能体后续运行的环境不同；在此处选择其中一个不会改变智能体路由。

**在 Paperclip 服务器主机上：**

1. 选择订阅登录。Paperclip 在主机上启动私有登录时显示 *正在准备浏览器登录…*。
2. Paperclip 显示一次性代码。使用 **复制代码** 将其复制。
3. 选择 **登录 OpenAI**，在 OpenAI 页面上输入代码并授权。
4. 当 Paperclip 显示 *“Codex CLI 已登录。点击连接以使用此账户。”* 时，选择 **连接**。尝试保持打开状态 30 分钟后过期。

如果您想在连接前使用不同的 OpenAI 账户，请选择 **使用其他账户**。如果尝试过期或失败，请选择 **重新开始登录**。

> **注意：** 在后台，Paperclip 使用其自己的 `CODEX_HOME` 和基于文件的凭据存储运行 `codex login --device-auth`，因此它既不读取也不干扰该机器上您个人的 `codex` 登录。

> **注意：** 30 分钟限制是针对服务器主机尝试记录的。我们尚未确定沙箱登录的等效时间；请尽快完成任何沙箱会话。

如果服务器主机登录不可用，您将看到 *“此托管实例上服务器主机订阅登录不可用。选择支持的登录环境或使用 API 密钥。”* 该限制针对的是 **在主机上** 登录，而非一般的订阅身份验证——如果已配置，沙箱登录环境仍然有效。除非管理员配置了受信任的运行时主机，否则此限制适用于公开暴露的已身份验证部署。

**在支持的沙箱中：**

1. 如果显示选择器，在 **登录环境** 中选择沙箱，并选择订阅身份验证。
2. 等待 Paperclip 准备登录链接，然后使用 **登录 OpenAI** 打开它。
3. 如果 Paperclip 显示设备代码，请在提供方登录页面上输入它。完成授权并返回 Paperclip。
4. 等待 Paperclip 完成连接。如果尝试过期或失败，请开始新的尝试；仅打开提供方页面并不能确认凭据已保存。

## 分配凭据

打开已保存的连接，在 **个人默认** 下使用 **设为默认** 设置您自己的账户。在智能体的 **连接** 选择器中，选择 **责任人的默认** 以使用每位责任人的账户，或选择命名的兼容个人账户或公司共享账户。保存智能体配置。

- **将其设为该提供方的默认值**，配置为使用责任人连接的智能体将使用每个人自己的账户。
- **为智能体选择特定的兼容连接**，以便符合条件的运行使用该账户，而非启动者的默认账户。

特定绑定不是无条件的。通过它的每次运行必须满足以下所有三点，否则运行将被拒绝：

| 要求 | 缺少它导致运行失败的原因 |
| --- | --- |
| 所选绑定与账户匹配 | 命名的 **个人** 账户使用显式个人绑定；**公司共享** 账户使用共享绑定。两种选择都不绕过人工访问 |
| 运行具有允许使用该凭据的 **责任人** | 人工共享受众控制每个绑定——*“此凭据未与责任人共享”* |
| 连接已 **为该智能体安装**（或全公司范围） | 否则 *“此连接不允许用于此智能体”* |

因此 **绑定不能替代责任人**：如果没有责任人，就没有人来评估权限检查，无论设置什么绑定，运行都会被拒绝。

**个人** 保持凭据归您所有；**公司共享** 使一个账户可供符合条件的智能体使用，其运行中的责任人在其人工受众中。模型在智能体配置中选定，而非在此处。

### 从智能体设置中连接

您也可以在智能体中连接账户而不离开智能体。在智能体的 **连接** 字段中：

- 当您当前的个人默认需要关注时，会出现 **重新连接账户**。它会再次登录您并修复该同一账户，因此其默认设置及其智能体访问权限保持不变。
- **连接账户…** 打开 **连接账户**，它会预先告知您新账户 *“将成为此提供方的默认账户。”* 您的任务使用它；其他人保留他们自己的默认设置。

当您以此方式连接全新账户时，您还会看到 **允许此公司中的所有智能体使用此账户处理我的任务**。如果您可以管理连接，它默认勾选。清除它可将账户仅限此智能体使用。无论如何，该账户仅支持您负责任的任务，且重新连接永远不会扩大账户已有的访问权限。如果登录成功但无法保存默认设置，**重试默认选择** 会在无需再次登录的情况下重试。

### 从任务中重新连接

如果任务显示身份验证卡片，请选择 **修复连接** 以在不离开任务的情况下修复所选账户。账户所有者再次登录；卡片说明何时需要其他所有者执行此操作。设置完成后，任务通过正常准入恢复。重新连接保留账户的受众和智能体访问权限。

如果您是责任人且尚未连接自己的 OpenAI 账户，任务聊天将显示 **需要 AI 连接** 而非失败，并显示标题为 **连接您的 OpenAI 账户** 的卡片。选择 **连接 OpenAI**，在卡片内连接您自己的账户，任务将自动恢复。Paperclip 永远不会借用队友的凭据来填补空缺。

## 检查使用限制

在将长任务交给智能体之前，您可以查看提供方剩余额度。打开已保存的账户，找到 **使用情况**，然后选择 **检查使用情况**。这适用于 OpenAI 订阅。API 密钥账户显示 *“此登录方式不可用。”* 而非按钮，因为提供方没有单一密钥的额度可供读取。

Paperclip 仅在您要求时读取限制。打开账户、列出连接和启动运行都不会触发检查。每个限制窗口显示已使用量及重置时间，并在提供方指示时标记为 **达到限制** 或 **已阻止**。**超额** 显示是否可用额外付费使用。提供方未报告的任何内容显示为 **未报告**，绝不显示为零。成功检查后，按钮变为 **刷新**。

检查是只读的。它不会将工作转移到其他账户，不会在达到限制时停止运行，不会刷新凭据，也不会购买额度。

| 消息 | 含义 |
| --- | --- |
| *“再次登录以检查使用情况。”* | 存储的凭据已过期。重新连接账户 |
| *“拒绝访问使用情况。”* | 提供方拒绝共享此凭据的使用情况 |
| *“检查次数过多。请稍后重试。”* | 提供方对检查本身进行了速率限制。您的额度不受影响 |
| *“重新连接以检查使用情况。”* | 账户当前不可用。请先重新连接 |

董事会用户可以使用 `GET /api/companies/{companyId}/ai-connections/{connectionId}/usage` 通过 API 运行相同的检查。

## 试用

首先阅读智能体配置，并记录其设置为使用哪个 AI 连接。该设置，而非运行输出，是可见预期凭据的地方。然后：

```txt
Reply with the single word: ready
```

**成功的回复证明** 某个 OpenAI 凭据已被接受，运行时兼容，且上述检查已通过。Paperclip 直接拒绝不合格的绑定，而不是回退到另一个账户，因此在显式绑定下完成的运行使用了授权的凭据。

**它不能证明哪个账户被计费。** Paperclip 内部解析提供方、方法、连接和责任人，但不按运行显示它们。要确认特定账户，请在 OpenAI 仪表板上稍后检查该账户的使用情况。

观察运行本身——连接可能看起来健康，但如果智能体不在 Codex 运行时上，仍可能在运行时失败。

> **注意：** 示例任务，非记录的测试结果。

## 故障排除和限制

| 问题 | 可能原因 | 修复 |
| --- | --- | --- |
| *“选择与此框架和模型兼容的 AI 连接”* | 智能体未在 Codex 运行时上运行 | 将智能体移至 Codex 运行时，或使用该运行时的提供方 |
| *“连接账户并选择您的个人默认”* | 智能体使用责任人的连接，但该人没有默认设置 | 连接账户并将其标记为默认 |
| *“此运行需要责任人选择 AI 连接”* | 运行没有责任人，且每个凭据检查都针对该人进行评估 | 为工作指定合格的责任人——将问题分配给一人，或作为一人启动运行。绑定共享连接 **不能** 绕过此限制 |
| *“此凭据未与责任人共享”* | 连接与命名人员共享，而责任人不在其中 | 将该人添加到连接的受众中，或让已在其中的人负责该工作 |
| *“此连接不允许用于此智能体”* | 连接未为该智能体或全公司范围安装 | 在连接的访问设置中为其安装 |
| 预览期间创建的订阅连接停止工作 | 预览时期的订阅凭据不可重用，必须重新建立 | 重新连接账户 |
| **登录** 不可用 | 此部署不提供登录环境 | 询问管理员是否可以启用沙箱登录环境；否则使用 API 密钥 |
| 服务器主机登录从不显示代码，或显示 *“登录期间服务器重启。重新开始登录。”* | Paperclip 服务器主机上缺少 `codex` CLI 或 Python 3，或服务器在尝试过程中重启 | 在主机上安装缺少的工具（Docker 镜像已包含两者），然后选择 **重新开始登录** |
| 状态 **已过期** 或 **需要关注** | 凭据轮换或密钥被撤销 | 重新连接账户 |
| 运行因配额错误失败 | OpenAI 的套餐或密钥限制，而非 Paperclip 限制 | 对于订阅，在已保存的账户上选择 **检查使用情况** 以查看哪个窗口已耗尽及何时重置。否则通过 OpenAI 检查使用情况 |

限制：一个连接是一个提供方账户，且不授予工具访问权限。订阅路径绑定于 Codex CLI，而非通用的 OpenAI API 凭据。
