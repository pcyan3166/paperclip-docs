# 检查 AI 账户使用情况

在将长期任务分配给智能体之前，请检查其将使用的账户配额。当您请求时，Paperclip 会显示提供商报告的内容；它不会根据任务成本估算订阅余额。

使用情况检查和 AI 连接设置不需要实验性设置。

## 检查已保存的账户

1. 打开 **连接器** 和已保存的 AI 账户。
2. 找到 **使用情况** 并选择 **检查使用情况**。
3. 阅读返回的限制和重置时间。当您需要另一个观察结果时，选择 **刷新**。

| 账户 | 支持的检查 |
| --- | --- |
| Anthropic 订阅 | 提供商报告的 Claude 使用窗口和超额使用（如可用） |
| OpenAI 订阅 | 提供商报告的配额窗口、重置时间和超额使用（如可用） |
| Grok 订阅 | 提供商报告的订阅限制和超额使用（如可用） |
| OpenRouter API 密钥 | 密钥信用额度限制、重置频率和免费模型限制（如可用） |
| 其他 API 密钥方法 | **此登录方法不可用。** |

该检查使用您选择的已存储连接。它不会探测环境中的 CLI 登录。打开账户页面不会自动触发检查。

## 阅读结果

限制可能显示为百分比、已使用金额和上限，或剩余配额。**达到限制** 意味着提供商报告限制已耗尽。**已阻止** 意味着它明确报告不允许使用。当提供时，会显示重置时间或频率。

缺失字段显示 **未报告**，绝不显示为零。Grok 可能省略包含计划的使用情况，某些 Claude 凭据可以运行模型但没有权限读取使用情况。**使用情况访问被拒绝。** 并不意味着您的配额已耗尽。

**超额使用** 描述提供商的额外使用状态。**开启 · 可用性未知** 意味着仅启用超额使用尚未建立可用的资金余额。观察时间戳告诉您何时读取了响应。

检查使用情况不会刷新您的凭据、购买信用额度、更改任务所选账户或停止正在运行的任务。这是提供商的观察结果，独立于 Paperclip 预算和每次运行的成本核算。

## 在成本页面查看配额

[成本页面](../guides/day-to-day/costs.md#quota-windows) 上的 **提供商** 选项卡也为 Anthropic 和 OpenAI 订阅账户显示 **订阅配额** 部分。它列出您被允许使用的每个已连接订阅账户，以其自己的名称列出，并使用该账户的已存储凭据读取——而不是在运行 Paperclip 的机器上的 CLI 登录。与 **检查使用情况** 不同，当您在提供商选项卡上时，它会每几分钟自动刷新一次。

如果刷新短暂失败，最后的良好读数会保留在屏幕上。如果账户需要连接或重新连接，读数将被清除，该部分会要求您在此处的 AI 连接中重新连接。

## 查看订阅每月费用

使用情况检查告诉您还剩多少配额；它们不告诉您计划的费用。为此，请使用 [成本页面](../guides/day-to-day/costs.md#subscriptions) 顶部的 **订阅** 磁贴。它列出您的智能体使用的每个订阅账户的月费，将共享席位计算一次，并允许您在 Paperclip 只能估算或完全无法确定时输入实际价格。

## 从任务中修复登录

当任务因 AI 凭据缺失或过期而无法启动时，它会显示一个身份验证连接卡片。打开该卡片并连接您的账户或重新连接现有账户。卡片成功完成后，任务将通过正常准入自动恢复。

只有账户所有者才能重新连接。如果任务使用他人的账户，卡片会解释谁必须恢复它。如果该账户不再对您可用，请要求所有者恢复访问权限或在智能体设置中选择另一个可用的连接。

重新连接会保留现有账户的受众、智能体访问权限和默认选择。它不会扩大共享范围。在智能体设置中，**重新连接账户** 修复您不可用的个人默认设置；**连接账户…** 允许您建立另一个账户。

## 故障排查

| 消息 | 处理方法 |
| --- | --- |
| **再次登录以检查使用情况。** | 重新连接已存储的账户。 |
| **使用情况访问被拒绝。** | 提供商拒绝了对该凭据的使用情况读取访问权限。如有必要，在提供商处检查使用情况。 |
| **检查次数过多。请稍后重试。** | 在另一次使用情况检查前等待。这不会消耗您的模型配额。 |
| **重新连接以检查使用情况。** | 在再次检查前恢复连接。 |
| **提供商不可用。请重试。** | 稍后重试；提供商未提供可用响应。 |
| **无法读取使用情况。请重试。** | 无法读取响应。缺失的数据不被视为零。 |

## API 等效操作

具有公司访问权限的经过 Board 身份验证的用户可以请求相同的观察结果：

```http
GET /api/companies/{companyId}/ai-connections/{connectionId}/usage
```

当连接具有多个符合条件的凭据授权时，传递 `?grantId={grantId}`。响应包括 `checkedAt`、`status`、提供商报告的 `limits` 和 `overage`，以及不可用时的 `errorCode`。您只能读取您被允许使用的凭据。
