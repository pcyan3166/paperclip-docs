# Discord

用户在 Discord 频道中提及您的智能体，Paperclip 便会开始工作。每个根级提及都会开启一个 Discord 线程，回复将返回到该线程中。

一个连接对应一个 Discord 服务器和一个智能体。

## 连接前准备

- **聊天连接器** 必须在该实例中启用。这是一个实验性设置，默认关闭，需由实例管理员在实验性设置中启用。若未启用，聊天设置将完全隐藏。
- 在机器人将驻留的 Discord 服务器上拥有 **Manage Server**（管理服务器）权限，以便安装机器人。
- 一个专用的 Discord 应用程序。请为此连接器使用一个新的应用程序，而不是复用已执行其他功能的机器人。
- 负责回复的智能体。

## 连接 Discord

### 1. 创建应用程序和机器人

在 [Discord 开发者门户](https://discord.com/developers/applications) 上，创建一个应用程序并为其添加一个机器人。然后：

- 在机器人上启用 **Message Content**（消息内容）意图。若未启用，Discord 将不传递任何消息文本，机器人虽显示在线但永远不会响应。
- 复制 **bot token**（机器人令牌）以及应用程序常规信息中的 **Application ID**（应用程序 ID）。
- 复制目标服务器的 **Server ID**（服务器 ID）。启用 Discord 的开发者模式，然后右键点击服务器并复制其 ID。

### 2. 在服务器上安装机器人

机器人需要在至少一个文本频道中拥有以下权限：

**View Channels**（查看频道）、**Send Messages**（发送消息）、**Create Public Threads**（创建公共线程）、**Send Messages in Threads**（在线程中发送消息）、**Read Message History**（读取消息历史）、**Add Reactions**（添加表情回应）、**Embed Links**（嵌入链接）和 **Attach Files**（附加文件）。

在设置过程中，Paperclip 会构建一个仅包含这些权限的安装链接，并限定在您提供的服务器 ID 范围内，这是安装机器人时出错率最低的方式。

### 3. 在 Paperclip 中连接

1. 打开 **Connectors**（连接器）并选择 **Discord**。
2. 在 **Access**（访问）步骤中，选择身份以及哪些智能体可以使用该连接。
3. 粘贴 **Bot token**（机器人令牌）、**Application ID**（应用程序 ID）和 **Server ID**（服务器 ID）。
4. 选择负责回复的智能体，并完成设置。

## 对话如何转化为工作

| 在 Discord 中 | 在 Paperclip 中 |
| --- | --- |
| 有人在频道中提及机器人 | 为连接的智能体创建一个任务，Paperclip 在该消息上开启一个线程 |
| 在线程内的回复 | 继续同一任务 |
| 在其他地方的新根级提及 | 启动一个独立任务及其专属线程 |

Paperclip 任务是权威记录。如果线程与任务出现不一致，以任务为准——这在有人中途编辑或删除 Discord 消息时很有用。

## 选择访问权限

可达范围由 Discord 决定，而非 Paperclip。机器人可以看到其角色在您安装它的那个服务器上可见的频道，Paperclip 中没有频道选择器。若要限制用户可以在哪里联系智能体，请在 Discord 的频道权限中限制机器人角色的可见频道。

提供商频道或仓库访问权限决定了消息可以到达集成的位置；但这本身并不授权智能体工作。Paperclip 还会检查发送者的关联身份和公司成员资格。关联用户必须是活跃的非查看者成员。未关联的发送者取决于连接的 **Allow unlinked people**（允许未关联人员）设置以及任何赞助要求。在邀请他人使用智能体之前，请审查这些控制措施。

连接的 **Any agent**（任意智能体）/ **Just agents I pick**（仅我选择的智能体）设置与其他连接器的工作方式相同；请参阅 [连接器访问权限如何工作](access-model.md)。请注意，回复智能体是在连接本身设置的。

## 尝试使用

1. 在机器人可见的频道中，使用简短的请求提及它：`@YourAgent hello, can you confirm you are connected?`
2. 预计几秒内会在您的消息上开启一个线程。
3. 确认在 Paperclip 中出现了一个匹配的任务，并分配给连接的智能体。

这一步骤在一个您控制的频道中，一次性测试了意图、权限、路由和任务创建。

> **注意：** 这是操作程序，而非记录在案的测试结果。首次尝试时请使用私有频道。

## 故障排查与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| Discord 未出现在 **Connectors**（连接器）中 | 该实例的 **Chat connectors**（聊天连接器）已关闭 | 请管理员启用 |
| 机器人显示在线但从不回复 | **Message Content**（消息内容）意图未启用 | 在开发者门户中启用，然后重新连接 |
| 机器人在某些频道回复，但在其他频道不回复 | 其角色无法看到那些频道，或无法在那里创建线程 | 在频道上授予列出的权限 |
| 设置因缺少权限被拒绝 | 机器人在任何文本频道中均缺乏所需权限 | 使用 Paperclip 生成的链接重新安装 |
| 提及未创建任务 | 提及是在现有线程内而非根消息中，或连接状态不健康 | 在频道级别进行提及；检查连接状态 |
| 回复来自错误的智能体 | 回复智能体是在连接上设置的 | 在连接上更改设置 |

限制：每个连接对应一个服务器和一个智能体。机器人角色无法看到的私有频道是不可达的。

> **注意：** 记录在案的启动工作方式是在频道中进行根级提及，这也是本页面描述的设置流程所测试的路径。Paperclip 的 Discord 适配器确实声明支持直接消息，但我们尚未验证直接消息是否能启动任务——在未经过自行测试之前，请勿基于此构建工作流。
