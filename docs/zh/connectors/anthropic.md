# Anthropic

Anthropic 连接为智能体提供运行 Claude 模型所需的凭据。这是模型访问权限，而非一组工具——没有需要授权的操作，**权限** 选项卡中也不会显示任何内容。

有两种身份验证方式：Claude 订阅或 Anthropic API 密钥。

## 连接前准备

- 需要一个 Claude 订阅，或来自 [Anthropic 控制台](https://console.anthropic.com/settings/keys) 的 Anthropic API 密钥。
- 一个在 Claude 运行时上运行的智能体：**Claude Code**，或 **Paperclip Runner → ACP 智能体 → Claude**。标准的 Anthropic 连接不兼容 Codex 或 OpenCode 框架。有关其他兼容 Claude 的端点，请参阅 [自定义模型提供商](custom-model-providers.md)。
- 仅适用于订阅登录：需要一个登录环境。Paperclip 提供两种类型——Paperclip 服务器主机本身，或支持交互式登录的沙箱环境。具体获得哪种取决于您的实例配置方式；请参阅 [使用 Claude 订阅](#with-a-claude-subscription)。

## 选择登录方式

| 方式 | 适用场景 | 计费 |
| --- | --- | --- |
| **订阅** | 您已付费使用 Claude 计划，并希望智能体运行消耗该计划额度 | 适用您 Claude 计划的使用限制 |
| **API 密钥** | 您需要按量计费、独立账单或无需交互式登录 | Anthropic 按令牌向密钥所属组织计费 |

订阅计划有其自身的使用限制，这些限制由 Anthropic 制定，而非 Paperclip。请向 Anthropic 查询当前计划条款，不要假设费率。

## 连接 Anthropic

1. 打开 **连接器** 并选择 **Anthropic**。
2. 选择登录方式。

设置是一个单屏界面，没有单独的访问步骤。账户保存后，您可以在已保存的连接中更改哪些人员和智能体可以使用它。

### 使用 API 密钥

粘贴密钥。Paperclip 将其存储为机密信息，之后不可读取。

### 使用 Claude 订阅

Paperclip 从不询问您的 Claude 密码。它通过 `claude` CLI 针对仅属于此连接的凭据目录进行登录。

登录在 **登录环境** 中运行，共有两种类型。您的实例提供哪些类型是配置事项，而非您在每次连接时做出的选择：

| 登录环境 | 所需条件 | 登录方式 |
| --- | --- | --- |
| **Paperclip 服务器主机** | 该主机上的 `claude` CLI 和 Python 3（Docker 镜像包含两者），以及一个活动的本地环境 | Paperclip 在主机上为您运行登录，并在浏览器中显示 **登录 Claude** 链接。您无需终端 |
| **沙箱环境** | 由管理员配置的支持交互式登录的沙箱提供商 | 登录发生在 Paperclip 提供的环境中；服务器主机上无需终端 |

如果可用多个环境，Paperclip 将显示 **登录环境** 选择器。请注意，用于登录的环境可能与智能体后续运行的环境不同；在此处选择不会更改智能体路由。

**在 Paperclip 服务器主机上：**

1. 选择订阅登录。Paperclip 在主机上启动私有登录时显示 *正在准备浏览器登录…*。
2. 选择 **登录 Claude**。Anthropic 的登录页面在新标签页中打开；在那里授权。
3. Anthropic 向您显示授权码。将其粘贴到 Paperclip 中的 **授权码** 字段并选择 **提交代码**。不要将其粘贴到任务或聊天中。
4. 当 Paperclip 显示 *“Claude Code 已登录。点击连接以使用此账户。”* 时，选择 **连接**。尝试在 30 分钟后过期。

如果您想在连接前使用不同的 Claude 账户登录，请选择 **使用其他账户**。如果尝试过期或失败，请选择 **重新开始登录**。

> **注意：** 在后台，Paperclip 运行 `claude setup-token`，并将 `CLAUDE_CONFIG_DIR` 指向仅用于此尝试的目录，因此它既不读取也不干扰该机器上您个人的 `claude` CLI 登录。

> **注意：** 30 分钟限制是针对服务器主机尝试记录的。我们尚未确定沙箱登录的等效时间；请将任何沙箱会话视为有时限的，并尽快完成。

如果服务器主机登录不可用，您将看到 *“此托管实例上服务器主机订阅登录不可用。选择支持的登录环境或使用 API 密钥。”* 该限制适用于 **在主机上** 登录，而非一般的订阅身份验证——如果已配置，沙箱登录环境仍然可用。除非管理员配置了受信任的运行时主机，否则此限制应用于公开暴露的已认证部署。

**在支持的沙箱中：**

1. 如果显示选择器，在 **登录环境** 中选择沙箱，并选择订阅身份验证。
2. 等待 Paperclip 准备登录链接，然后使用 **登录 Claude** 打开它。
3. 完成提供商登录，然后将授权码返回到 Paperclip 中显示的代码字段。不要将其粘贴到任务或聊天中。
4. 等待 Paperclip 完成连接。如果尝试过期或失败，请开始新的尝试；仅打开提供商页面并不能确认凭据已保存。

## 分配凭据

打开已保存的连接，在 **个人默认** 下使用 **设为默认** 设置您自己的账户。在智能体的 **连接** 选择器中，选择 **责任人的默认** 以使用每位责任人的账户，或选择命名的兼容个人账户或公司共享账户。保存智能体配置。

已连接的账户尚未成为运行使用的账户。有两种绑定方式：

- **将其设为该提供商的默认值**。配置为使用责任人连接的智能体将采用该人员设为默认的任何账户，因此每个人的运行都使用其自己的凭据。
- **为智能体选择特定的兼容连接**，使符合条件的运行使用该账户，而非启动者的默认账户。

绑定特定连接并非无条件。通过该连接的每次运行仍必须满足以下所有三点，否则运行将被拒绝：

| 要求 | 缺少此要求导致运行失败的原因 |
| --- | --- |
| 所选绑定与账户匹配 | 命名的 **个人** 账户使用显式个人绑定；**公司共享** 账户使用共享绑定。两种选择都不绕过人工访问 |
| 运行具有 **责任人**，且该人员被允许使用凭据 | 人工共享受众控制每个绑定。如果连接限制为命名人员，责任人必须是其中之一——*“此凭据未与责任人共享”* |
| 连接已 **为该智能体安装**（或全公司范围） | 否则 *“此连接不允许用于此智能体”* |

实际后果：**绑定不能替代责任人。** 如果运行没有责任人，权限检查就没有评估对象，无论设置何种绑定，运行都会被拒绝。

**个人** 连接保持为您所有；**公司共享** 使一个账户可供符合条件的智能体在责任人属于其人工受众的运行中使用。模型本身在智能体配置中选择，而非在此处。

### 从智能体设置中连接

您也可以在不离开智能体的情况下连接账户。在智能体的 **连接** 字段中：

- 当您当前的个人默认需要关注时，会出现 **重新连接账户**。它再次登录并修复同一账户，因此其默认设置和智能体访问权限保持不变。
- **连接账户…** 打开 **连接账户**，它会预先告知您新账户 *“将成为此提供商的默认账户。”* 您的任务使用它；其他人保留其自己的默认设置。

当您以此方式连接全新账户时，您还会看到 **允许此公司中的所有智能体使用此账户执行我的任务**。如果您可以管理连接，它默认勾选。取消勾选以将该账户仅限此智能体使用。无论哪种方式，该账户仅支持您负责任的任务，且重新连接永远不会扩大账户已有的访问权限。如果登录成功但无法保存默认设置，**重试默认选择** 会在无需再次登录的情况下重试。

### 从任务中重新连接

如果任务显示身份验证卡片，请选择 **修复连接** 以在不离开任务的情况下修复所选账户。账户所有者再次登录；卡片会说明何时需要其他所有者执行此操作。设置完成后，任务通过正常准入恢复。重新连接保留账户的受众和智能体访问权限。

如果您是责任人且尚未连接自己的 Claude 账户，任务聊天将显示 **需要 AI 连接** 而非失败，并显示标题为 **连接您的 Claude 账户** 的卡片。选择 **连接 Claude**，在卡片内连接您自己的账户，任务将自动恢复。Paperclip 从不借用同事的凭据来填补空缺。

## 检查使用限制

在将长任务交给智能体之前，您可以查看提供商剩余额度。打开已保存的账户，找到 **使用量**，然后选择 **检查使用量**。这适用于 Anthropic 订阅。API 密钥账户显示 *“此登录方式不可用。”* 而非按钮，因为提供商没有单一密钥的额度可供读取。

Paperclip 仅在您请求时读取限制。打开账户、列出连接和启动运行都不会触发检查。每个限制窗口显示已使用量及重置时间，并在提供商指示时标记为 **达到限制** 或 **已阻止**。**超额** 显示是否可用额外付费使用。提供商未提供的任何内容显示为 **未报告**，绝不显示为零。成功检查后，按钮变为 **刷新**。

某些 Claude 订阅凭据允许运行模型但不允许读取使用量。在这种情况下，您将看到 *“使用量访问被拒绝。”* 这是存储登录的限制，而非计划耗尽的迹象，仅为模型访问而再次登录不会改变此情况。

检查是只读的。它不会将工作转移到其他账户，不会在达到限制时停止运行，不会刷新凭据，也不会购买额度。

| 消息 | 含义 |
| --- | --- |
| *“再次登录以检查使用量。”* | 存储的凭据已过期。重新连接账户 |
| *“使用量访问被拒绝。”* | 提供商拒绝为此凭据共享使用量 |
| *“检查次数过多。请稍后重试。”* | 提供商对检查本身进行了速率限制。您的额度不受影响 |
| *“重新连接以检查使用量。”* | 账户当前不可用。请先重新连接 |

董事会用户可以使用 `GET /api/companies/{companyId}/ai-connections/{connectionId}/usage` 通过 API 运行相同的检查。

## 试用

在运行任何内容之前，阅读智能体配置并注意其设置为使用哪个 AI 连接——责任人的默认连接，或命名的兼容连接。该设置，而非运行输出，是可见预期凭据的地方。

然后给智能体一个简短、低成本的任务：

```txt
Reply with the single word: ready
```

**成功回复证明了什么：** 某个 Claude 凭据被接受，智能体的运行时兼容，且上述权限检查通过。当绑定不符合资格时，Paperclip 会直接拒绝运行，而不是静默回退到另一个账户，因此在显式绑定下完成的运行确实使用了授权的凭据。

**它未证明什么：** *哪个* 账户为此付费。Paperclip 在解析凭据时内部记录提供商、方法、连接和责任人，但这些字段未在界面中按运行显示。如果您需要确认特定账户被计费，请在运行后在提供商自己的仪表板上检查该账户的使用量。如果智能体设置为使用责任人的默认连接，回复不会告诉您读取了谁的默认设置。

关注运行而非状态徽章：即使连接显示为已连接，如果智能体的运行时不匹配，运行时仍可能失败。

> **注意：** 示例任务，非记录的测试结果。

## 故障排除与限制

| 问题 | 可能原因 | 修复 |
| --- | --- | --- |
| *“选择与此框架和模型兼容的 AI 连接”* | 智能体未在 Claude 运行时上运行，或所选模型与连接不匹配 | 将智能体移至 Claude 运行时，或使用该运行时自己的提供商 |
| *“连接账户并选择您的个人默认”* | 智能体使用责任人的连接，但该人员对此提供商没有默认设置 | 连接账户并将其标记为默认 |
| *“此运行需要责任人选择 AI 连接”* | 运行没有责任人。每个凭据检查都针对该人员评估 | 为工作指定合格的责任人——将问题分配给一人，或以其身份启动运行。绑定共享连接 **不能** 绕过此限制：权限检查仍需有人评估 |
| *“此凭据未与责任人共享”* | 连接与命名人员共享，且责任人不在其中 | 将该人员添加到连接的受众中，或让受众中的某人负责该工作 |
| *“此连接不允许用于此智能体”* | 连接未为该智能体或全公司范围安装 | 在连接的访问设置中为其安装 |
| **登录** 不可用 | 此部署未提供登录环境 | 询问管理员是否可以启用沙箱登录环境；否则使用 API 密钥 |
| 服务器主机登录从不显示 **登录 Claude**，或显示 *“登录期间服务器已重启。重新开始登录。”* | Paperclip 服务器主机上缺少 `claude` CLI 或 Python 3，或服务器在尝试过程中重启 | 在主机上安装缺少的工具（Docker 镜像已包含两者），然后选择 **重新开始登录** |
| *“另一个登录仍在进行中”* | 之前的尝试尚未过期 | 完成或等待开放的尝试结束，然后重试 |
| 状态 **已过期** 或 **需要关注** | 订阅凭据轮换，或 API 密钥被撤销 | 重新连接账户 |
| 运行因提供商配额错误失败 | Anthropic 的计划或密钥限制，而非 Paperclip 限制 | 对于订阅，在已保存的账户上选择 **检查使用量** 以查看哪个窗口已耗尽及何时重置。否则向 Anthropic 检查使用量 |

限制：一个连接对应一个提供商账户。此连接器不授予任何类型的工具访问权限。模型选择和智能体的运行时在智能体上配置，而非在连接上。
