# 重新授权、撤销或断开连接

这是四种不同的操作，常被混淆。它们的区别在于哪些内容会被保留。

| 操作 | 凭据 | 操作设置 | 智能体访问权限 | 连接记录 |
| --- | --- | --- | --- | --- |
| **重新连接** | 被替换 | 保留 | 保留 | 保留 |
| **替换凭据** | 被替换 | 保留 | 保留 | 保留 |
| **暂停** | 保留 | 保留 | 保留 | 保留，但不可用 |
| **撤销某个身份** | 针对该身份移除 | 保留 | 保留 | 保留 |
| **删除** | 移除 | 消失 | 消失 | 消失 |

## 重新连接过期的登录

适用于令牌在提供商处已过期或被撤销的 OAuth 连接。

1. 打开连接器。它会显示 **需要重新连接 — 请再次登录以恢复访问权限。**
2. 选择 **重新连接**。
3. 完成提供商的登录流程。

该连接将保留其身份、智能体访问权限以及所有操作设置。只有存储的令牌会发生变更。

Paperclip 不允许重新连接静默地更改身份。在恢复时，存储的身份具有权威性，因此如果重新连接链接指向错误的提供商，将被拒绝，并提示 *"此重新连接链接与保留的连接提供商不匹配。"*

对于个人连接，必须由连接的所有者进行重新连接。Paperclip 会在创建 OAuth 状态之前验证调用者是否为该连接保留的主体——管理者无法代表您重新同意授权。

## 替换 API 密钥

适用于在提供商处已轮换密钥的基于密钥的连接。

1. 打开连接器的高级设置。
2. 选择 **替换存储的凭据** 并 **粘贴您的新密钥**。
3. Paperclip 会在保存前针对提供商验证该密钥。

*"该密钥验证未通过。请尝试其他密钥。"* 表示提供商拒绝了该值。*"您没有权限替换此身份的凭据。"* 表示该凭据属于您未管理的身份。

## 暂停连接器

**暂停连接** 会阻止智能体使用该连接器，但不会删除任何内容。列表随后会显示 **已暂停 — 智能体目前无法使用。** 取消暂停即可恢复。不会重新授权，也不会丢失任何数据。

当您希望立即停用某个连接器，但尚未确定是“修复它”还是“移除它”时，请使用此功能。

## 撤销某个身份

可以单独撤销组织身份，同时保留连接和其他授权。Paperclip 会要求确认 — *"撤销组织身份？"* — 并警告 *"已安装的智能体将立即失去此共享身份。"*

相关路由：

```http
DELETE /api/tool-connections/{connectionId}/grants/{grantId}
DELETE /api/tool-connections/{connectionId}/grants/{grantId}/delegations/{delegationId}
```

撤销是立即生效的。正在进行的运行将在其下一次调用时失去该身份。

## 删除连接

**移除连接** 或 **删除连接** 将移除该连接及其所有关联内容：凭据、已发现的操作列表、操作设置以及智能体访问权限列表。此操作不可逆。

```http
DELETE /api/tool-connections/{connectionId}
```

在 Paperclip 中删除连接并不会在提供商处撤销授权。如果服务保留了授权记录——例如 OAuth 应用授权、机器人安装或 API 密钥——请也在提供商处将其移除。请从连接器自身页面上的提供商控制台链接开始操作。

## 断开连接后

- 依赖该连接的智能体将报告工具不可用，而不是静默跳过工作。
- 从该连接的审核请求中创建的信任规则将保留在公司的工具策略中，直到您撤销它们。
- [活动日志](../guides/day-to-day/activity-log.md) 将保留生命周期记录。
