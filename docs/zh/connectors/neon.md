# Neon

智能体可以操作您的 Neon 无服务器 Postgres——管理项目和分支、运行 SQL 以及检查模式。

> **警告：** 请使用开发项目。Neon 的托管服务器授予广泛的项目和数据库管理权限，且 Neon 本身建议将其用于开发和测试。在连接任何包含生产数据的系统之前，请审查写入和破坏性操作。

此连接器默认启用写入工具。它们受 Paperclip 的操作设置管理，但默认状态并非只读——您需要主动选择只读模式。

## 连接前准备

- 一个具有您希望智能体使用的项目访问权限的 Neon 账户。
- 对于密钥方法：一个 **Neon API 密钥**，在 Neon 控制台的 [设置 → API 密钥](https://console.neon.tech/app/settings/api-keys) 下创建。关于应选择哪种密钥，请参阅下文。
- 可选：您希望将此连接限制为使用的单个项目的 **项目 ID**。您可以在 Neon 控制台的 **项目设置 → 常规** 中找到它。
- 在连接之前而非之后决定只读模式。

有两种连接方式：

| 方法 | 所需条件 | 适用场景 |
| --- | --- | --- |
| **使用 Neon 登录** | 无需创建任何内容。您在浏览器中批准访问 | 大多数用户的首选路径 |
| **使用 API 密钥** | 您自行创建的 Neon API 密钥 | 当浏览器登录不适用时 |

Paperclip 不会自动从一种方法回退到另一种。您选择的方法会保存在连接中，并在每次重新连接时复用。

### API 密钥方法所需的密钥类型

**您的 Neon 密钥** 字段接受以 `napi_...` 或 `neon_project_key_...` 开头的密钥。Neon 提供几种类型的密钥，其权限范围不同：

| 类型 | 权限范围 |
| --- | --- |
| **项目范围密钥** | 单个项目，具有编辑器权限 |
| **个人或组织密钥** | 该账户或组织可访问的所有项目 |

对于单个开发项目，优先使用项目范围密钥。Paperclip 无法扩大现有密钥的允许权限——它只能缩小权限。

## 连接 Neon

1. 打开 **连接器** 并选择 **Neon**。
2. 阅读主按钮上方的访问说明行。它说明了连接以谁的身份登录以及哪些智能体可以使用它。若要选择不同身份、缩小智能体范围或使用其他登录方法，请选择 **更改**。
3. 检查您将如何认证。设置默认从 **使用 Neon 登录** 开始。若要改为粘贴 API 密钥，请选择 **更改** 并选择 **使用 API 密钥**。
4. 可选地选择 **更改** 以显示 **固定到项目 ID** 和 **只读模式**，然后填写其中任意一项。这两项均非必需——您可以直接使用 Neon 的默认设置继续。
5. 完成设置。对于浏览器登录，在 Neon 中批准访问；对于密钥方法，粘贴密钥并继续。

Paperclip 需要一个公共 HTTPS 源，或如 `http://localhost:3100` 这样的回环 HTTP 源，以完成浏览器登录。普通的 HTTP tailnet 主机名不算作回环——请在连接前切换到 HTTPS。

## 限定连接范围

| 控制项 | 建议 |
| --- | --- |
| **固定到项目 ID** | 将连接固定到单个开发项目。仅限小写字母、数字和连字符，最多 64 个字符 |
| **只读模式** | 除非智能体确实需要更改某些内容，否则请开启此模式。它将 SQL 限制为 `SELECT` 查询和模式检查 |

无效的项目 ID 会在 Paperclip 联系 Neon 之前被拒绝，因此拼写错误会立即显现。

> **注意：** 项目固定和只读模式作为请求参数传递给 Neon 的 MCP 服务器——由 Neon 强制执行，而非 Paperclip。您看到的实际效果是项目或工具集合的范围缩小，但强制执行边界在于提供商。Paperclip 自身对运行内容的控制在于操作设置。

## 选择访问权限

项目范围取决于 Neon 登录或密钥所携带的权限，如果您设置了项目固定，则进一步受其限制。账户、组织和项目权限属于 Neon，而非 Paperclip。

此处的写入权限涵盖范围很广：创建和删除项目和分支、管理角色、数据库和计算资源、恢复快照、应用模式更改以及运行 SQL。这些更改无法从 Paperclip 中撤销。

每个发现的操作默认均为 **允许**，包括写入和破坏性操作。连接后，打开连接的 **权限** 屏幕，并将删除、分支重置和计算资源更改至少设置为 **先询问**。请参阅 [设置操作权限](action-permissions.md)。

## 试用

使用元数据读取，而非针对真实数据的查询：

```txt
List the Neon projects this connection can reach and the branches in each. Do not run any SQL or change anything.
```

预期结果是与您的 Neon 控制台匹配的项目和分支列表。这可以在不触及行数据的情况下确认凭据和项目范围。

不要通过迁移、分支重置或写入查询来验证。

> **注意：** 此为示例任务，而非记录的测试结果。

## 故障排除与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 设置拒绝项目 ID | 它包含小写字母、数字和连字符以外的字符，或长度超过 64 个字符 | 从 Neon 控制台的 **项目设置 → 常规** 中复制项目 ID |
| 浏览器登录无法完成 | Paperclip 在非回环主机名上通过普通 HTTP 提供服务 | 使用 HTTPS，或如 `http://localhost:3100` 这样的回环源 |
| 密钥有效但无法访问某个项目 | 项目范围密钥覆盖的是另一个项目，或账户没有访问权限 | 使用针对正确项目的密钥，或在 Neon 中授予访问权限 |
| 缺少写入工具或 SQL 写入失败 | **只读模式** 已开启，且 Neon 正在遵守该设置 | 这是推荐的设置；仅在确有需要时再关闭 |
| 发生了您未预期的更改 | 写入工具默认启用且该操作被允许 | 开启只读模式，或将这些操作设置为 **先询问** 或 **关闭** |
| **需要关注** | 密钥已被撤销或登录已过期 | 选择 **重新连接** |

限制：项目固定和只读模式是 Neon 遵守的请求，而非 Paperclip 的保证，且两者都不能替代使用开发项目。Paperclip 无法回滚数据库更改——恢复依赖于 Neon 的分支和快照。
