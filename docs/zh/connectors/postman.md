# Postman

智能体可以处理您的 Postman 工作区、集合和环境——读取 API 定义，并在更完整的功能组中生成代码并进行更改。

在配置凭据之前有两个决策，任何一项出错都意味着需要重新开始。

## 首先决定区域和功能组

**区域** 决定了端点以及您如何认证：

| 区域 | 认证方式 |
| --- | --- |
| **美国** | 浏览器登录 |
| **欧洲** | API 密钥——欧洲端点不支持浏览器登录 |

**功能组** 决定了连接暴露的工具数量：

| 组 | 涵盖内容 |
| --- | --- |
| **最小集** | 最小的工具目录——核心工作区、集合、环境、模拟和规格工具 |
| **代码** | 专注于从 API 定义生成代码的工具集 |
| **完整集** | 完整的 Postman API 工具目录 |

> **警告：** **最小集是较小的目录，而非只读目录。** Postman 自身的文档就是这样描述的，其发布的最小集列表包括 `createCollection`、`createWorkspace`、`putCollection`、`updateWorkspace`、`publishMock`、`duplicateCollection` 和 `runCollection`。选择最小集并不能阻止智能体创建、更改、发布或运行内容。如果您希望保持只读状态，这取决于 Paperclip 的操作设置，而非功能组。

尽管如此，请从 **最小集** 开始——较小的目录对于您和智能体来说都更容易推理——但在完成设置后，将其包含的写入操作设置为 **先询问** 或 **关闭**。

区域和组在连接中是固定的。若要更改其中任何一项，请创建新连接。

## 连接前准备

- 一个能够访问智能体所需工作区的 Postman 账户。
- 对于欧洲区域，需要一个 Postman API 密钥。

## 连接 Postman

1. 打开 **连接器** 并选择 **Postman**。
2. 阅读主按钮上方的访问权限行。它说明了连接以谁的身份登录以及哪些智能体可以使用它。若要选择不同身份、缩小智能体范围或使用其他登录方法，请选择 **更改**。
3. 检查所选选项是否与您的区域和功能组匹配。若要选择其他选项，请选择 **更改**。
4. 对于美国区域，完成 Postman 的浏览器登录。对于欧洲区域，粘贴您的 Postman API 密钥。

## 选择访问权限

工作区、集合和环境的访问范围由 Postman 决定：连接可以看到认证账户或密钥所能看到的内容。Paperclip 没有工作区选择器，因此通过认证一个访问较少工作区的账户来缩小访问权限。

> **警告：** Postman 环境通常将 API 密钥、令牌和密码作为变量存储。能够读取环境的智能体可以读取这些值。在此真正有帮助的控制措施是使用受限账户进行认证，并将密钥保留在共享的 Postman 环境之外——同时结合已发现的工具列表和 Paperclip 的操作权限。

工具集因用途而异；不要假设它们构成逐步更宽的权限层级。检查您所选端点的已发现操作。在使用生成的代码之前请进行审查，并分别为每个可用操作设置权限。

有一个工具需要特别关注：`runCollection` 存在于最小集列表中，运行集合意味着针对集合目标发出其请求。明确决定智能体是否应该能够执行此操作，如果不能，请将其设置为 **关闭**。

在 **权限** 选项卡上将写入和破坏性操作设置为 **先询问** 或 **关闭**。在此连接器中，这是只读控制。参见 [设置操作权限](action-permissions.md)。

## 尝试使用

```txt
List the Postman collections you can see and tell me how many requests are in the first one. Do not change anything.
```

将集合列表与您在 Postman 中看到的内容进行比较。这可以同时确认凭据、区域端点和智能体的权限。

> **注意：** 这是示例任务，而非记录的测试结果。

## 故障排查与限制

| 问题 | 可能原因 | 解决方法 |
| --- | --- | --- |
| 未提供浏览器登录 | 您选择了欧洲选项；欧洲端点需要 API 密钥 | 使用欧洲密钥选项，或者如果账户托管在美国，则使用美国区域 |
| 认证成功但看不到任何内容 | 账户位于另一个区域 | 使用与 Postman 账户托管位置匹配的选项进行连接 |
| 缺少预期的工具 | 连接使用了较窄的功能组 | 使用 **代码** 或 **完整集** 创建新连接 |
| 写入被拒绝 | 操作设置为 **先询问** 或 **关闭** | 检查 **权限** 选项卡。不要期望功能组是原因——最小集也包含写入工具 |
| 智能体在 **最小集** 上更改或发布了内容 | 最小集是较小的目录，而非只读目录 | 在 **权限** 选项卡上将写入操作设置为 **关闭** |
| 缺少工作区 | 认证账户无法看到它 | 在 Postman 中授予访问权限；无需重新连接 |
| **需要关注** | API 密钥已被撤销，或登录已过期 | 选择 **重新连接** |

限制：每个连接仅限一个区域和一个功能组。Paperclip 中无工作区选择。不要根据功能组的名称推断只读访问权限。Postman 自身的计划限制适用。
