# 智能体聊天

并非每次与智能体的对话一开始都是一项定义清晰的任务。有时你只是想边想边说、问个问题，或者先弄清下一步该做什么，然后再把它转化为工作。

**智能体聊天**让你与每个智能体保持一个持续对话。你们一起讨论目标，智能体会询问所需信息；当有实际工作要做时，它会将工作交给普通任务处理。任务完成后，智能体会回到对话中告诉你完成了什么。

## 启用此功能

1. 前往 **Settings → Experimental**（设置 → 实验性功能）。
2. 开启 **Agent Chat**（智能体聊天）。此功能目前仍处于实验阶段，默认关闭；启用后，你就能与智能体进行持续对话。

与此页面上的其他开关一样，该设置对整个实例生效。在 Paperclip Cloud 上，此功能可能由系统为你管理，此时会显示 **Managed by Paperclip Cloud**（由 Paperclip Cloud 管理）锁定标记——请参阅[开关被锁定时](overview.md#if-a-toggle-is-locked)。

## 打开聊天

启用后，简化侧边栏的 **Work**（工作）分组中会出现 **Chat**（聊天）。智能体会显示在对话旁边的独立栏中，因此你无需离开页面即可切换聊天。较旧的侧边栏则会把 Chat 放在 Inbox（收件箱）下方。

点击后，Paperclip 会带你回到本公司中最近打开的智能体聊天。如果你还没有与任何人聊过，页面会询问 *“你想与谁交谈？”*，并展示几个智能体供你选择；其余智能体可通过 **Browse all agents**（浏览所有智能体）链接查看。

聊天区域在对话旁有自己的侧边栏，标题为 **Chat**：

- **Teammates**（队友）会先列出现有对话，随后列出其他可聊天的智能体。每一行显示智能体头像、名称和头衔。正在回复的智能体会显示 **Working…**（正在工作…）；已暂停或已终止的智能体会显示相应状态。
- **Find an agent**（查找智能体）可按名称或角色筛选列表。
- **Add chat**（添加聊天，**+** 按钮）会打开 **Chat with an agent**（与智能体聊天），其中可搜索公司内的所有智能体。如果你已经与某个智能体有对话，它会标记为 **Open chat**（打开聊天）；否则标记为 **New chat**（新建聊天）。选择一个智能体后，其对话会立即打开。
- 底部的 **Browse all agents**（浏览所有智能体）会带你前往完整的智能体列表。

无论是否已选择智能体，侧边栏和标题栏都会保持在原位，因此切换对话时页面不会跳动。

## 每个智能体只有一个对话

你与每个智能体恰好只有一个对话。若为已经聊过的智能体添加聊天，只会重新打开原对话，并显示 **“每个智能体只有一个对话。从上次中断处继续。”**，因此无需整理重复的对话。

对话在后台实际对应一项任务，因此使用与普通任务页面相同的编辑器、聊天记录、附件和文档。有关这些控件，请参阅[聊天式任务](task-chat.md)。

右侧面板默认显示 **Tasks**（任务），列出该智能体在整个公司范围内参与的任务，而不只是此聊天中创建的任务。你可以搜索、筛选或排序任务卡片，然后打开其中一项，在新的浏览器标签页中查看工作内容。**Artifacts**（成果）会显示智能体生成的文件，并为每个文件提供返回对应任务的链接。该面板最多显示最近 200 项任务和最近 500 项成果，到达上限时会通知你；若要查看全部内容，请使用公司的 Tasks（任务）或 Artifacts（成果）页面。

你可以通过面板的 **+** 菜单打开 **Artifacts** 或 **Properties**（属性）。查看成果时，对话仍会并排显示。

对话遵循公司常规的任务可见性规则。队友可以阅读你与智能体的对话，但只有你能在其中发送消息。每个人与每个智能体都有各自的对话。

## 先讨论，再移交工作

聊天中，智能体的职责是理解你的需求，而不是悄悄开始构建。它会询问缺少的重要信息，可以与你一起研究并起草计划；有了实质性工作要做时，它会为这项工作创建普通任务，并分配给合适的智能体、放入合适的项目，同时附上上下文、你们商定的计划以及完成标准。对话本身不会转变为实际工作。

与任务一样，你仍可在编辑器中选择 **Plan mode**（计划模式）或 **Ask mode**（询问模式）。询问模式会让智能体保持只读；计划模式用于澄清需求并制定计划。

回复完成后，对话会等待你的下一条消息。空闲聊天不算未完成的工作。

## 获取结果

你不必一直检查聊天创建的任务。任务标记为完成后，你正在聊天的智能体会被唤醒，并在对话中发布更新，说明完成了什么以及在哪里可以找到结果。如果它回复前有多项任务完成，会在同一条更新中汇总。如果任务完成时智能体正在回复，则会在它的下一轮发言中发布更新。

只有已完成的任务会以这种方式汇报；进行中、受阻、失败和已取消的任务不会在聊天中通知。若更新发布前你重新打开了任务，该更新就会取消；再次完成任务后会发送新的更新。

## 使用 /new 开始新会话

长对话会积累大量上下文。单独发送 **/new**——编辑器会将其显示为 **New session**（新会话），并提示 *“在保留对话历史的同时，从全新上下文开始。”*——智能体下一轮就会从干净的上下文开始。你说过的所有内容、计划和关联任务仍会显示在对话中；分隔线会标出新会话的起始位置。

对话暂停后，也可以用 **/new** 恢复：编辑器会提示 *“发送 /new 以开始新会话并恢复此对话。”*

上一会话中尚未回答的问题会失效，因此旧问题不会继续占用编辑器。在 **/new** 之前移交的任务，其更新不会发布到新会话中。任务和结果不会受到影响，你仍可从对话中打开它们。

## 关闭此功能时

关闭 **Agent Chat** 会移除 **Chat** 入口并停止接收新消息，但不会删除任何内容。已经开始的轮次会继续运行，现有对话仍可通过任务链接阅读。若在关闭时打开聊天页面，会看到 *“Agent Chat 已禁用。请在 Experimental 设置中启用。”* 重新启用后，一切都会恢复原样。

## 注意事项

- 这是一项仍在积极迭代的实验性功能。不同版本间，标签、布局以及智能体决定如何移交工作的方式都可能变化。
- 智能体将对话拆分为任务的效果取决于智能体及其模型。依赖这些任务前，请先阅读智能体创建的任务。
- 只有当你的实例运行包含此行为的版本后由聊天移交的任务，才会以这种方式返回结果。更早移交的任务不会追溯汇报。
