# 环境

默认情况下，智能体执行会在 Paperclip 主机本身运行。**Environments**（环境）允许你定义可重复使用的具名执行目标——通过 SSH 连接的远程计算机，或服务提供商插件提供的沙盒——并按实例、项目或智能体进行分配。每个环境都有自己的配置；对于沙盒环境，还支持连接探测和可重复使用的自定义镜像。

![实例设置中的环境管理界面](../../user-guides/screenshots/light/experimental/environments.png)

## 此功能的用途

一台计算机无法满足所有智能体的需求。有些工作需要与主机隔离，有些需要更强大的机器，还有些需要预先准备好工具链（安装可能要花几分钟）。环境让你可以通过一组执行目标来路由执行——包括预先准备一次并在每次执行中重复使用的沙盒镜像——而不是让所有智能体共享主机上的同一套环境。

## 启用此功能

1. 前往 **Settings → Experimental**（设置 → 实验性功能）。
2. 开启 **Enable Environments**（启用环境），说明文字为：*“在公司设置中显示环境管理，并允许控制项目和智能体的环境分配。”*

**Settings** 中的 **Environments** 标签页始终可见，但在开启此标记之前，页面只会提示你前往实验性设置启用环境。此标记还会在智能体和项目配置中显示环境选择器。

## 设置你的第一个环境

1. 打开 **Settings → Environments**（设置 → 环境）。
2. 点击 **+** 按钮（其悬停提示为 **Add environment**，添加环境），然后选择驱动程序：
   - **Local**（本地）——在 Paperclip 主机上运行（将默认行为作为明确的选项列出）。
   - **SSH**——远程计算机：需指定主机、用户、密钥和远程路径。
   - **Sandbox**（沙盒）——作为插件安装的沙盒服务提供商（请参阅[沙盒服务提供商](../reference/adapters/sandbox-providers.md)）；每个服务提供商都有自己的配置字段。
3. 保存前使用 **Test**（测试）探测连接。
4. 可选择将一个环境标记为实例的 **Default**（默认）环境——除非另有指定，否则智能体会继承该环境。

然后将工作路由到该环境：

- **按智能体设置**——智能体配置表单会增加 **Environment override**（环境覆盖）选择器，其中包含 *“Default: …”* 以及每个环境（格式为 `name · driver`，即名称 · 驱动程序）。
- **按项目设置**——项目配置的执行工作区设置中会增加 **Environment** 下拉菜单。它位于隔离工作区控件内，因此还需要启用[隔离工作区](isolated-workspaces.md)，并且至少有两个可选环境。

### 自定义沙盒镜像

对于沙盒环境，编辑环境后会显示 **Custom image**（自定义镜像）面板：启动一个临时设置沙盒，在浏览器中打开终端，安装并登录智能体所需的内容，然后将该计算机捕获为可重复使用的镜像，以供未来执行启动使用。完整操作流程请参阅[自定义沙盒镜像指南](../guides/projects-workflow/custom-sandbox-images.md)。

## 关闭此功能时

这只是界面层面的开关：环境页面内容、智能体环境覆盖选择器和项目下拉菜单会隐藏，但现有环境、默认环境分配以及已捕获的镜像都会保留。重新开启后，一切都会恢复原样。

## 注意事项

- 沙盒环境需要支持运行执行的服务提供商插件；此外，自定义镜像捕获还要求服务提供商声明支持交互式设置和模板捕获。
- 无论此标记是否开启，只有董事会运营人员可以管理环境。
