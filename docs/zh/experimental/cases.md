# 案例

有些工作成果的生命周期比创建它的任务更长。一篇博客文章可能经过研究、起草、编辑，并在数月后更新；一个文档页面可能在每次发布时修订。如果每个步骤都对应一项独立任务，那么你真正关心的内容——文章或页面——就没有统一的归属位置。

**案例**为它提供了这样的归属位置。案例是一条持久记录，包含类型（例如 `blog_post`）、标题、可选键（例如 `<release>/<slug>`）、结构化字段、标签、文档、附件以及相关任务的链接。案例也可以设置父案例和子案例，因此一个活动可以包含多篇独立文章。

智能体通过案例 API 创建和更新案例。你可以在 **Cases**（案例）页面中跟进它们。

## 启用此功能

案例属于实验性功能，默认关闭。前往 **Settings → Experimental**（设置 → 实验性功能），开启 **Cases**（案例，设置键 `enableCases`）。卡片说明为：*“任务创建并持续迭代的长期工作成果（博客文章、推文串……）。添加 Cases 标签页和智能体案例 API。”*

启用后，侧边栏会出现带有 **beta** 标记的 **Cases**。与此页面上的所有开关一样，该设置对整个实例生效。

再次关闭后，标签页会隐藏，案例 API 也会被阻止——卡片说明中写道：*“现有案例数据会保留。”*

## 让智能体创建案例

你无法从看板创建案例，案例由智能体创建。如果公司还没有任何案例，**Cases** 页面会显示一段简短示例，你可以将其添加到技能中，大意如下：

> “创建一个类型为 blog_post 的案例，字段为 {slug, target_audience, publish_url}，键为 &lt;release&gt;/&lt;slug&gt;。”

Paperclip 技能中的 `references/cases.md` 介绍了智能体使用的 API。

## 浏览案例

在侧边栏中打开 **Cases**，即可查看公司的案例。

- **Search cases...**（搜索案例…）会在你输入时筛选列表。
- **Filters**（筛选器）可按 **Type**（类型）、**Status**（状态）、**Project**（项目，包含 **No project**，无项目）和 **Label**（标签）缩小结果范围。**Clear filters**（清除筛选条件）会重置筛选器。默认情况下，列表会隐藏状态为 **Done**（已完成）或 **Cancelled**（已取消）的案例。
- **Sort**（排序）可按 **Last updated**（最近更新）、**Created at**（创建时间）、**Title**（标题）、**Status**（状态）、**ID**、**Type**（类型）或 **Project**（项目）排序。
- **Group**（分组）可按 **Type**（类型，默认）、**Project**（项目）、**Status**（状态）或 **None**（不分组）排列行。
- **Columns**（列）可选择要显示的 **ID**、**Key**（键）、**Title**（标题）、**Type**（类型）、**Status**（状态）、**Updated**（更新时间）、**Created at**（创建时间）、**Project**（项目）和 **Parent case**（父案例）。
- 树形按钮可在平面列表和父子树视图之间切换。

你可以用方向键浏览列表，然后按 Enter 打开案例。浏览器会按公司记住你的视图设置。

每一行都有状态选择器，因此可以直接在列表中更改案例状态：**Draft**（草稿）、**In progress**（进行中）、**In review**（审阅中）、**Approved**（已批准）、**Done**（已完成）或 **Cancelled**（已取消）。

## 查看案例

点击案例即可打开。标题区域显示案例标识符、键、标题、类型，以及父案例和子案例（如果有）。标题旁边有：

- 状态选择器，用于更改案例状态；
- **⋮** 菜单，其中包含 **Copy as markdown**（复制为 Markdown，可复制标识符、标题、键、类型、状态和标签）以及 **Properties**（属性，用于打开属性面板）。

标题区域下方有三个标签页：

- **Overview**（概览）——案例文档、描述（如果有）和所有附件。
- **Properties**（属性）——案例类型、键和标签（可在此添加或移除标签）、结构化 **Fields**（字段）、**Linked tasks**（关联任务）、子案例以及附件数量。
- **Activity**（活动）——案例最近的历史记录。

## 注意事项

- 案例仍处于实验阶段。不同版本间，标签、布局和 API 结构可能会变化。
- 你无法从看板创建案例，也只能在看板中更改案例状态和标签。其他所有更改都由智能体通过 [Cases API](../reference/api/cases.md) 执行。
