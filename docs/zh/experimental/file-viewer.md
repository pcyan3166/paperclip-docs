# 实验性文件查看器

智能体处理任务时，有趣的产出往往不是评论串，而是文件：它撰写的报告、修改的代码、保存的截图。没有文件查看器时，你只能在磁盘上查找工作区，或者要求智能体把内容粘贴到评论里。

实验性文件查看器解决了这个问题。它会在每个任务详情页中添加控件，让你**直接在浏览器中浏览和预览任务工作区文件**——搜索文件树、打开文件、阅读渲染后的 Markdown、查看图片和视频、复制内容、下载文件，以及分享可直接定位到特定文件和行的深层链接。

![从任务中浏览工作区文件](../../user-guides/screenshots/light/experimental/file-viewer-browse.png)

## 启用此功能

1. 前往 **Settings → Experimental**（设置 → 实验性功能）。
2. 开启 **Experimental File Viewer**（实验性文件查看器），说明文字为：*“显示任务详情控件，以便浏览和预览相对于任务工作区的文件。”*

此设置对整个实例生效，并立即生效。

## 查看入口

启用后，每个任务详情页都会提供多个入口，打开同一个查看器：

- 任务标题区域中的**文件图标按钮**（仅桌面端）——悬停提示为 *“Open file… (g f)”*。
- 在任务页面任意位置按 **`g f`** 键盘快捷键。
- 命令面板中的 **“Open file in this issue…”**（在此任务中打开文件…）条目。
- 任务 **Workspace**（工作区）卡片中的两个链接：**Browse files…**（浏览文件…）和 **Open file by path…**（按路径打开文件…）。
- **行内文件链接**——智能体评论、文档或成果引用工作区文件时，这些引用会变成可点击的标签，打开查看器并定位到该文件。指向工作区文件的工作成果也会以可点击的 **Artifacts**（成果）标签显示。

## 使用查看器

查看器会以大型面板形式在任务上方打开，提供两种模式：

- **Browse mode**（浏览模式）——包含搜索框（*“按名称或路径搜索文件…”*）和文件树。默认情况下会列出最近更改的文件，因此智能体最近的工作会显示在顶部。输入文字即可筛选；使用方向键和 Enter 打开结果；也可以输入完整路径并按 Enter 直接跳转。面包屑会显示当前所在的文件夹。
- **File mode**（文件模式）——左侧为可调整大小的文件树侧边栏，右侧为预览区：
  - **文本和代码**会带行号显示。如果你通过包含行号的深层链接打开文件，该行会高亮并滚动到可视区域。
  - **Markdown** 可在 **Rendered**（渲染）和 **Raw**（原始）视图间切换。
  - **图片和视频**会直接以内嵌方式预览。

文件模式下的标题栏控件包括：**Download**（下载）、**Copy file contents**（复制文件内容）、**Copy link to this file view**（复制此文件视图的链接）和 **Close**（关闭）。复制的链接会编码文件、行和工作区信息，因此队友打开后会直接看到你当前查看的位置。如果你是在浏览模式中打开的文件，可以点击 **Back to files**（返回文件列表）或按 Esc 回到列表。

## 关闭此功能时

此标记仅控制界面。关闭后，标题栏按钮、快捷键、命令面板入口和 Workspace 卡片链接都会隐藏，行内文件引用也会显示为不可点击的普通标签。不会删除任何内容；重新开启后，所有功能都会恢复。

## 限制和保护措施

- 任务必须使用**本地工作区**。远程工作区会显示 *“远程工作区预览即将推出”*；如果某个隔离工作树已被清理，查看器会告知你，而不会尝试预览。
- **文件大小限制**：文本文件最大 512 KB，图片和视频最大 10 MB。更大的文件会提示 *“文件太大，无法预览”*（仍可下载）。
- **敏感路径会被阻止。** 查看器会拒绝访问名称类似密钥的文件（`.env`、SSH 密钥、`.npmrc`、`.netrc`、kubeconfig，以及 `.aws`、`.ssh`、`.docker`、`.kube` 下的所有内容），并跳过 `.git` 和 `node_modules`。它也会拒绝工作区以外的路径遍历。
- 查看器是**只读的**——可以浏览、预览、复制和下载，但不能编辑。
- 较大的文件夹每次分页显示 100 个项目，并提供 *“从此文件夹加载更多”* 控件。
